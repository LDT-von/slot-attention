2026-11-02。范围：方案与零件，禁止本轮任何神经网络初始化、前向、反向、训练和患者执行。面向高水平研究的可实施起点，不是已达到顶刊发表标准的方法。模型效果、创新性、可辨识性和临床价值尚未验证。

## 二、明确的问题、模块作用与验收对象

候选核心问题：**在生存预测预算固定的条件下，能否减少无效重复，同时保留单模态增量与跨模态交互所需内容？** 双视图、自监督、槽池化、方差正则分别有先例；本方案没有把它们计作多个独立创新。只有该问题的可证伪机制及控制验证成立，才有资格进一步提出贡献。

“共有候选”仅指被跨模态对齐、并有各自任务压力的角色组；“私有候选”指保留本模态内容且不被强制跨模态对齐的角色组；“交互候选”指表达跨模态乘积的读出项。它们不等于PID原子或生物学独有因素。需要区别共有冗余（可能有益）与同一分支内部无效复制，不能把所有redundancy都作为坏信息惩罚。

## 三、初版模块接口与信息流

输入为同患者配对的 WSI [B,Nw,Dw]、组学身份已嵌入tokens [B,No,Do]，以及两侧 real_mask。不是原始RNA、图片或不定维通路列表。患者配对、同一患者多slide合并、gene/pathway身份、已有缺失、split/feature schema的验证由未来adapter负责。真实数据及身份保存在忽略目录，公共配置仅保存接口和来源摘要。

1. 每侧复用同一个编码器处理两个视图，不能为view1/view2初始化不同编码器。`RoleSlotEncoder` 有7个共有查询与1个私有查询，joint slot竞争；输出全部槽与最后一次真实token读取矩阵。
2. `AllSlotPool` 先逐槽phi再均值，得到 cw,uw,co,uo，宽度固定。role为空则返回零；所有槽可访问，但均值可能丢信息。参数分离与位置索引只能定义角色，不能识别共有/私有语义。
3. `SummaryProjector` 仅供SSL使用，每模态/每角色一个，两个视图共享同一实例；预测继续读高维summary。投影器可隐藏未对齐成分，验收必须同时检查投影前后和原槽，不能只报低维loss。
4. 基础读出严格定义为

   `a = b + 0.5*(hc(cw)+hc(co)) + hw(uw) + ho(uo)`。

   每一项只访问单一模态；hc两侧共享。g=(cw+co)/2只输出诊断，不喂入联合MLP。这个加性只在hazard logit尺度成立，sigmoid后概率并不加性。
5. 可选交互为 `j = Wo[(Aw[cw,uw]) * (Ao[co,uo])]`，三个线性映射均不含bias；总logits=a+j。关闭交互时不计算j。固定编码下基础项的跨模态混合有限差分应为零。乘积项仍可能经常量坐标表达主效应；它不是纯交互正交化、PID或因果作用。
6. 输出分项logits、两侧共有独立logits，供task NLL和以后归因；不要额外接联合head，否则会破坏加性控制。独立共有监督只约束可预测性，不能证明纯共有。不要给单个私有槽强加独立预后损失，以免排斥只有联合有效的信息。

目前这些零件已由 `components/assembly.py` 组装为一个无数据副作用的模型容器，`components/adapters.py` 提供元数据边界；仍未执行模型初始化、前向、反向或训练。没有新的 dataset 或 CLI。旧model.py及旧5项tensor测试不代表新零件已经验收。

## 四、损失定义、统计条件与默认策略

离散生存损失使用 `completed_intervals`：若event=true，该数是事件区间索引；若censor，该数是已经完整存活的区间数，可取0..K。不得将删失所在bin未经转换直接当已完整存活区间。分箱边界、边界相等的约定、训练折拟合与验证/测试固定映射是未来adapter的必备元数据。事件索引只能0..K−1。目标是删失适当的预测损失，不直接估计完整事件时间互信息。

计划目标：L_task + λc*(两侧共有NLL均值) + λw*L_intra_w + λo*L_intra_o + λcc*L_cross_common + λuu*L_cross_private + λv*L_variance。每项独立返回；所有辅助权重在首个纯任务基线中为0，后续逐项增加。此处没有经过验证的最优权重。lambda=0必须跳过该项计算，避免关闭SSL时仍因B=1报错。不存在额外“协同MI损失”；交互表达能力先由任务及已知答案验证。

相关计算以**独立患者**为行。当前适配用对角、非对角分别均值归一，与DeCUR求和不同；归一方式必须记录。epsilon保有限值，返回方差诊断，不在塌缩时直接抛出“零方差”而让训练无法继续。组装容器只在对应权重大于零时要求第二视图、患者键和相关统计，关闭项惰性跳过。零点仍可能零梯度，epsilon不是反塌缩解决方案。

对中心化单位方差特征，单矩阵I目标必要条件为D≤B−1。若四项都要求精确理想值，共有两侧完全一致、两私有互不相关，且每模态内共有/私有维度正交，则进一步需要 `dc + dp_w + dp_o ≤ B−1`。默认接口示例p=2/role、最小B=8只满足必要秩条件，不证明估计可靠或有效超参数。实际有效batch不明时不应组装训练；梯度累积、两视图、patch数、槽数均不自动增加相关统计的独立患者数。可达性guard是本适配的保守选择；秩不足不等于原DeCUR的代理损失完全不可优化。

反塌缩区分：(a)患者轴常量，(b)同患者多槽复制，(c)两模态角色塌缩。variance floor只针对(a)；SCM/SRO针对(b)的代理，但精确对称点可零梯度；不对(c)一概惩罚，因为任务共有部分应允许一致。无随机打散标签或强制所有槽正交的默认方案。

## 五、视图设计与额外臂的准入

病理先计划两组独立无放回索引，记录overlap、Jaccard及padding。短袋两视图含全部相同内容是合法但无新增视图信息的情形，重排不能伪称增强。增强预算为两次编码，公平对照需匹配视图数量、unique patch预算、更新数和墙钟/内存。原图颜色/形态增强属于另一个含特征重提取成本的实验，当前零件不实现。

组学提供连续特征遮蔽索引计划，保护预先定义的通路最少可观察量，原始missing与人工mask分开。不能用结果/验证折选择保护组。离散突变初版只支持恒等视图；噪声只登记上界且要求训练折统计来源，不实际生成或改变数值。视图是否保留预后信息必须验证，双视图自监督本身不保证。eval固定view计划是新协议候选，不能悄悄替换原版20次随机评估。

SRO/SCM/R4暂不再复制实现：SRO需read_attention+real_mask，明确只惩罚同role组还是全8槽；SCM需逐槽表示；R4需无target query的decoder和训练折固定内容目标。私有组1槽不存在组内配对，不得把零惩罚写成成功。它们各自一次只改一变量；历史旧结构的分数不能当新结构的配对对照。反塌缩不能只以重复槽降低作为成功。

## 六、分阶段验收与停止条件

| 阶段 | 要回答的问题 | 准入/停止条件 |
| --- | --- | --- |
| S0 本轮 | 契约和数学边界是否一致 | 只标准库检查+源码编译；不触发模型。当前执行范围到此 |
| S1 后续另行授权 | 零件数学/张量实现是否正确 | CPU固定小张量测试：NLL手算、梯度/有限差分、padding污染不变、role置换、空role、零权重lazy skip、四项退化、参数load一致、加性差分=0；不通过就先修实现 |
| S2 后续另行授权 | 学习是否保留必要内容 | 锁定seed/预算的共享、独有、XOR、加性、噪声、复制、非线性共同信息及带噪G任务；必须包括混合多因素而非只单XOR。与无SSL/无增强/匹配头容量比较；保留负结果，失败不扩大患者队列 |
| S3 后续另行授权 | 是否有稳定患者增量 | adapter doctor通过后，再锁定队列。原版、普通融合、DeCUR式适配/PIBD可比版本、加性/交互、共/私比例及各损失消融；不用本轮自动启动 |

S2分开冻结编码的读出可用性与端到端可学习性；患者轴是重采样单位，不把seed/重复评估当患者。联合优于单模态仍可能只叠加两个独有信息；联合优于加性头仍有头容量/优化混杂。配对打乱或删槽会造分布外输入，只报告敏感性，不当作PID证据。真正的PID还缺目标、冗余定义、删失处理及可一致估计方法，当前不声称完成。

S3训练/调参/选权/最终测试必须分离，验证最佳epoch是模型选择指标；在独立数据上用删失适当的NLL、校准与辨别指标，配对患者不确定性、多臂选择控制、缺失模态与跨队列稳健性。生存数据适用的独立删失假设需说明。尚无患者授权，本文件不列run命令。

## 七、近邻与贡献边界

- [DeCUR, ECCV2024](https://www.ecva.net/papers/eccv_2024/papers_ECCV/papers/04236.pdf)：共有/私有维度与同模态双视图学习已有先例，不能以模块组合声称首创。
- [PIBD, ICLR2024](https://arxiv.org/abs/2401.01646)：病理—组学生存信息瓶颈/分解的直接近邻，后续必须按真实实现和输入条件作可比基线。其Prototypical Information Disentanglement缩写与Partial Information Decomposition不可混为一谈。
- [FactorCL, NeurIPS2023](https://proceedings.neurips.cc/paper_files/paper/2023/hash/6818dcc65fdf3cbd4b05770fb957803e-Abstract-Conference.html)：任务相关共有/独有与增强假设已有研究，不能把标签相关分解本身当新问题。
- [Deep Sets](https://arxiv.org/abs/1703.06114)：非线性逐元素映射再聚合不是本项目的新理论，也不保证有限宽度完整保留信息。
- [VICReg](https://arxiv.org/abs/2105.04906)：方差/协方差正则已有先例，不把可选variance floor单独计为创新。
- [Φ-Omni](https://arxiv.org/html/2609.02118v1)：三模态自监督及融合表示的信息量代理不等于本方案删失生存目标的精确PID。在两源标准PID恒等式下，联合MI减边际MI之和等于协同减冗余，本文将其视为解释限制，不复制为精确协同度量。

目前能交付的是模块可实施性、无数据副作用的组装接口、可证伪问题与明确验证路线。决定是否能形成高水平论文的核心证据尚缺，不能预先用期刊等级代替这些检验。
