## 二、P5核心问题逐项回答

### 问题1：原版代码是否提供padding mask，数据准备是否会产生补零行？

**代码检查结果：**

**a) slot_attention.py (Slot Attention层)**
```python
def forward(self, inputs, num_slots: int | None = None):
    # inputs: (batch, seq_len, dim)
    # 没有任何mask参数
```
→ **原版Slot Attention层不接收padding mask**

**b) dataset_survival.py (数据准备)**
```python
# 第288-292行
if n_samples < self.dataset_factory.num_patches:
    wsi = torch.cat([wsi, torch.zeros(...)], dim=0)  # 补零行
```
→ **仅在patch数不足时产生补零行**

**实际缓存状态：**
```
WSI cache shape: torch.Size([360, 256, 1024])
验证集零行统计: min=0, max=0, mean=0.00
验证集有零行的患者: 0/71
```
→ **当前验证缓存中没有补零行**（所有71名验证患者均有≥256个真实patch）

**结论：** 代码有能力产生补零行，但**当前历史缓存中没有零行**。无法用现有缓存直接验证零行干预效果。

### 问题3：这种零行干预能否代表真实无关组织？

**证据状态：未证实**

**区别：**
| 属性 | 零行 | 真实无关组织 |
|------|------|--------------|
| 数值 | 全0 | 非全0 |
| 语义 | 无信息 | 可能有弱信息 |
| 注意力 | 会被分配0权重 | 可能被分配非零权重 |
| 训练分布 | 未见分布 | 真实分布 |

→ 零行干预≠真实无关组织占槽
