2. 已完成工作
统一顺序：S0 → S4 → R1 → R2 → R3 → R4 → R5 → S1 → S2 → S3 → S5。
沿用当前fold0、seed3：11种方法×1fold×1seed=11个拟议训练任务。S6保留登记但不进入本次队列；R0仅作S0算法别名，不额外排基线。
采用相同逐例compact前向与逻辑batch8；每个样本独立重设原生RNG，避免S5变长槽数影响下个样本。各组同初态、患者顺序和缓存。
每个逻辑batch只做一次core更新，原生辅助损失按患者均值，生存NLL按batch归约；附加损失先在每位患者内平均、再按患者/模态等权平均。
这样可以在同一协议下共用本次唯一S0，而不能借用以前vectorized或其他数据/预算的S0/R0成绩。
当前仍保留3轮、256真实patch、20次评估重放的短程诊断预设；用户本次指定单fold，未新指定完整训练轮数。不能把3轮通过当成充分训练后的效果。
单fold适合初筛；最终可报告本fold匹配结果，不能据此宣称跨折泛化稳定改进。
