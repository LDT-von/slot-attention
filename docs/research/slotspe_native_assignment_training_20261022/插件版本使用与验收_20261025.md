# SlotSPE 插件版本：实现、对照与执行

日期：2026-10-25。三个候选模块与独立实验入口已实现。本地检查仅用人工生成数据，患者收益尚未检验。
数学定义、假设与证明见[实施计划](互信息与解耦模块实施计划_20261025.md)，当前检查回执见[PROGRESS](../../PROGRESS.json)。

## 1. 哪一个更有创新空间

本轮有限文献核对下的设计判断是 **V2 > V3 > V1**，并非完整查新或审稿结论。

| 候选 | 当前定位 | 需要证明的额外贡献 |
|---|---|---|
| V1，监督VIB | 可运行的信息压缩基线 | 是否优于相同随机瓶颈但没有KL的对照；仅迁移VIB本身创新有限 |
| V2，内容约束共享/私有分解 | 主要研究候选 | 是否减少重复槽而保留不同内容；排除空分支、缩尺度和噪声造成的假改善 |
| V3，关系残差 | V2之后的可选扩展 | 是否优于参数量接近的逐槽MLP，并优于宿主已有self/cross attention |

[Deep VIB](https://arxiv.org/abs/1612.00410) 已有随机编码与KL压缩；
[MISA](https://arxiv.org/abs/2005.03545) 已有共享/私有分解；
[PIBD](https://proceedings.iclr.cc/paper_files/paper/2024/hash/9ead108421b202494d01b5060d12aa34-Abstract-Conference.html) 已将瓶颈、共享/私有知识用于癌症生存。
[Relation Networks](https://proceedings.neurips.cc/paper/2017/hash/e6acf4b0f69f6f6e60e9a815938aa1ff-Abstract.html) 已提出可插拔关系推理。
因此不能以“互信息+解耦+生存”或“再加一个关系层”本身作为新颖性结论。
这里C是**同一模态内部、各槽的共享分量**；两个模态分别参数化，不把它冒称为已对齐的跨模态共同生物因素。

## 2. 一个规范实现，九个固定preset

| preset | 新增机制 | 附加目标 |
|---|---|---|
| B0_native | 完整原版旁路，无新增参数 | 无 |
| B1_gram | 原生槽的几何正则参照 | 10 × off-diagonal cosine² |
| V1_mean | 确定性均值映射 | 无KL；同注册参数不等于同有效容量 |
| V1_noise | 独立Gaussian重参数采样 | β=0 |
| V1_vib | 与V1_noise相同结构和采样 | β=0.001，KL按两模态4096个潜变量平均 |
| V2_content | C64/U192、私有内容恢复 | Hungarian内容MSE，权重1 |
| V2_separate | 同一分解及内容头 | 再加0.1 HSIC和0.1共享方差项 |
| V3_capacity | 固定V2分离结构，加逐槽残差 | 与V2_separate相同 |
| V3_relation | 固定V2分离结构，加两两关系残差 | 与V2_separate相同 |

所有臂都从同一个原生初始化训练；V3与V2也使用相同的分解初始化，**没有先训练父模型再多训练30轮**。
关系MLP每模态115072个参数，逐槽容量对照115168个参数，相差0.0834%；末层为零、残差系数为1。
只替换每模态的首次预测槽调用；decoder、cross/self attention读取该替换值。后续OMIC-from-WSI联合重构调用保留。
原生主损失、辅助生存与重构公式/权重保留，不添加梯度裁剪、不修改padding策略。

代码入口：

- `slotspe_proof/slot_bottleneck.py`：V1随机后验、解析KL与均值对照。
- `slotspe_proof/slot_disentanglement.py`：V2分解、私有内容匹配、可导尺度规范化与HSIC。
- `slotspe_proof/slot_relations.py`：V3关系与容量残差。
- `slotspe_proof/prediction_slots.py`：唯一的原生槽调用定位与hook清理实现。
- `slotspe_proof/plugin_host.py`：统一宿主、preset与患者逻辑batch的附加目标。
- `slotspe_proof/plugin_engine.py`：配对训练、best/last、逐轮验证、原始回执和分阶段门禁。
- `slotspe_proof/plugin_queue.py`：只用标准库的计划、配置检查与显式执行分派。
- `scripts/run_slotspe_plugins.py`、`configs/slotspe_plugins_fold0_seed3.json`：统一命令与冻结配置。

原版 `third_party/SlotSPE/` 和现有十一臂队列继续使用原文件；本研究入口不混入旧队列。

## 3. 本地计划与生成检查

默认仅打印计划，不导入torch、pandas或训练引擎，不读取患者数组，也不创建训练输出：

```bash
python -B scripts/run_slotspe_plugins.py --plan
```

独立的生成数据检查使用8名人工样本、4096个人工patch、原生256维/8槽/10迭代，逐preset完成1个逻辑优化步：

```bash
python -B scripts/run_slotspe_plugins.py --check-generated \
  --output-root local_evidence/slot_plugins_generated_check_run01
```

此生成检查的输入特征维度为8、人工通路宽度为3和5，并非真实UNI2-h或患者数据。
输出存在时拒绝覆盖；再次检查需换一个新的忽略目录。
单元测试还覆盖原生旁路输出/损失/梯度/RNG、主预测梯度贯通、尺度方向梯度、内容塌缩下界、关系置换与XOR拟合。
这些检查证明接口和所测性质，不证明真实预测收益。

Windows完整测试需固定子进程编码，避免中文路径的GBK/UTF-8混用：

```powershell
$env:PYTHONIOENCODING = 'utf-8'
python -B -m pytest tests -q
```

只收集公开的 `tests/`；不扫描忽略目录中的历史交付副本，不删除历史副本来消除重名。

## 4. 将来恢复服务器连接后的患者执行

用户已授权逐版本执行，当前按其要求暂缓连接。以下是实现中的入口，**不表示这些命令已经执行**。
沿用服务器现有 `SLOTSPE_METADATA_ROOT` 和 `SLOTSPE_FEATURES_ROOT`，在已确认的trisurv环境运行。

```bash
python -B scripts/run_slotspe_plugins.py --doctor
python -B scripts/run_slotspe_plugins.py --plan --stage v1
python -B scripts/run_slotspe_plugins.py --run --stage v1 \
  --output-root local_evidence/slot_plugins_blca_uni2h_fold0_seed3_run01
```

doctor只检查文件、哈希与运行环境；不加载模型或患者数组。`--run`才执行患者工作。
v1只执行B0/B1与三种V1，共5臂；后续阶段不会自动启动。
逐臂回执验收后，在同一输出根目录追加：

```bash
python -B scripts/run_slotspe_plugins.py --run --stage v2 \
  --output-root local_evidence/slot_plugins_blca_uni2h_fold0_seed3_run01
python -B scripts/run_slotspe_plugins.py --run --stage v3 \
  --output-root local_evidence/slot_plugins_blca_uni2h_fold0_seed3_run01
```

v2要求v1完成且产物哈希一致，v3要求前两阶段同样通过。已开始的阶段不重跑、不覆盖，失败时保留目录并使用新队列定位问题。
代码、配置、CSV、库版本、初始化或前序产物变化会拒绝继续；输出仅允许Git忽略的 `local_evidence/` 子目录。
患者输入/缓存、ID、权重、逐患者预测、槽数组和失败日志均保存在该私有输出内，不加入公开清单。

固定范围：BLCA/UNI2-h、fold0/seed3、30 epochs、训练4096 patch、逻辑batch8、20次选模后复评。
训练每次重新无放回抽样、短bag补零；内容参考只看本次有效真实行，padding不成为内容目标。
验证采用B1、全部真实patch，不抽样、不补零。训练集分箱、内容标准化与随机投影仅在训练输入拟合。
HSIC显式拼接不同患者的计算图；尾批若仅1人则合入前批，患者不因数量少被丢弃。

## 5. 选模、结果与失败边界

官方选模规则：best初值0.0，每轮验证一次，`>=`更新，因此同分保留较晚epoch；同时保存last。
先确定best权重，再按预定随机调度复评20次，报告全部分数及均值/标准差；不从20次中挑最大值。
验证集选模本身带来的偏差属于官方行为；比较多版本还会增加版本选择偏差，单折试点不作泛化结论。

核心输出为每臂 `protocol.json`、`curve.json`、`best.pt`、`last.pt`、`eval_repeats.json`、`raw_repeat_*.pt` 和 `summary.json`。
队列根目录保存共享初始化/内容参考、原生来源与输入哈希、分阶段完成/失败和产物哈希。
V1区分原槽/后验均值/采样槽，避免把噪声降低cos称为有用分工；V2同时报告内容误差和常量预测下界。
非有限损失/梯度/参数、HSIC尺度或核退化、来源变化、缺失前序产物都明确失败，不静默修正、跳过患者或降低预算。
初始化、数据准备、训练和生成检查的异常均保留失败记录，不将失败目录恢复成成功目录。

主要比较：V1_vib对V1_noise；V2_separate对V2_content；V3_relation对V3_capacity，并分别对照B0/B1。
9臂共270个单臂epoch是试点预算；20次复评不增加独立患者数或独立训练数。
远端 `fe23ab2` 新增的既有十一臂结果记录已保留；本轮未重新验收其原始患者产物。旧队列的固定末轮/预算验证与新队列的best-val/全真实验证不同，不能直接拼表排名。
若本试点通过，论文级比较仍需在同一协议下加入既有R5、S1等强参照，并做独立泛化检验；当前九臂主要服务机制归因。
是否有效取决于匹配患者实验。公式、合成通过和模块数量都不能代替患者效益证据。
