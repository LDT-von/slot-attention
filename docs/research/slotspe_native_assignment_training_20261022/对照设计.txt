原版 SlotSPE：S0–S4 槽内分配的匹配训练设计

一、路由/任务
SPE-08 / 原版 SlotSPE 问题线。研究对象为当前 SlotSPE。误切换宿主后新建的13个文件和执行包已在校验备份后从当前工作树移除，错误的两条当前进度记录同步清理；既有历史证据与原始源码保留。

二、完成的设计纠正
统一使用 third_party/SlotSPE 的原版模型作为宿主；模型中已有两处可比较的模块分别是病理 Slot Attention 和组学 Slot Attention。
S0：两侧原计算。
S1：两侧仅将槽内分配替换为普通 Sinkhorn。
S2：病理 Slot Attention 使用 MESH 式分配；组学侧原计算。
S3：病理侧原计算；组学 Slot Attention 使用 MESH 式分配。
S4：两侧 Slot Attention 均使用 MESH 式分配。
不加入原型汇总层，不引入 DCT 宿主或跨模态运输。

三、比较含义
S1-S0：两侧归一化约束的整体变化。
S4-S1：在相同归一化设定上增加完整 MESH 式扰动与成本优化的变化，不单独归因于熵优化。
S2/S3-S0：更换病理/组学槽聚合模块的整体变化。
S4-S2/S3：两侧修改的组合是否带来进一步变化。
S2/S3 各自没有同侧的单独 Sinkhorn 臂，不能据此单独识别该侧 MESH 相对普通 Sinkhorn 的增量。

四、必须保留的控制
同一数据划分、完全病例、训练折分箱、真实 patch 缓存、参数集合和初始权重、批次顺序、步数、原生损失、checkpoint 规则与评估次数。
保留原版 Top-K、self/cross 读取、原生门控梯度关系、辅助生存和重建公式及系数；不顺手修复其他问题。
原生高斯/Gumbel 基础随机流配对；MESH 使用独立随机流。训练后的参数可以自然分化，不强行要求各臂后续初槽数值相同。
需注意原版 slot_attention_omic 在 WSI→组学重建中也被复用。S3/S4若按模块替换，会覆盖该模块所有调用；实现及收据必须明确这项范围，不能宣称只干预了基因输入读取。不得悄悄删除该重建调用。
先检查 S0 与无适配器原版的完整前向、各损失和梯度一致，再进行真实队列。原版源码字节不变，通过独立适配器接入。
