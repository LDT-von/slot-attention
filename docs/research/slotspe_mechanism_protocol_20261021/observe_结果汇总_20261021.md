## 2. 逐项结果

### P2 冗余与碎片化 —— 机制证据支持

原版 8 槽、每患者 5 重复、77 患者。P2 直接捕获原生 slot 向量与每头 token 读取矩阵，
未改模型、未改 forward。

| 指标 | WSI 中位 | OMIC 中位 |
|---|---|---|
| 槽对余弦（去对角，28 对） | 0.997867 | 0.996305 |
| 槽对余弦最小值 | 0.991369 | 0.991098 |
| 槽对归一化 L2 | 0.050737 | 0.062897 |
| 中心化有效秩（满值 8） | 2.538596 | 4.710160 |
| 注意力余弦（去对角） | 0.999998 | 0.999977 |
| 注意力共享质量 | 0.999320 | 0.997280 |
| 注意力总变差 | 0.000680 | 0.002720 |
| 注意力 JS（bits） | 0.000001 | 0.000008 |
| 归一化分配熵 | 1.000000 | 0.999998 |
| 有效 token 支持 | 255.9998 / 256 | 328.9967 / 329 |

WSI 侧每个 token 的分配熵等于 log(8) = 2.079441，即每个 token 被 8 个槽近似等分。
槽向量首主成分占方差 76.6%，代数秩 7 而有效秩 2.54。

**判定：机制证据支持表示/读取冗余。** 协议要求的三项条件（高余弦、读取高度重叠、
表示秩低）同时成立，且跨 77 患者高度一致（槽对余弦最小值 0.9884，跨患者极差 0.0013）。

限定：按协议，此结论**不能**直接推断预测信息没有独特贡献，也**不能**直接登记为
预测损害。碎片化需要"原本同一个实例/结构"的独立边界，本次因缺内容标签，
`group_fragmentation` 仅为训练折特征簇描述，**未**作为组织碎片化证据。

负对照已生效：槽对计数为 S(S-1)/2 = 28，零向量与零秩均标为不可定义，未伪造为 0。

### P7 目标不一致 —— 部分机制证据支持

同一次原生 train-mode 前向、同患者同 dropout 抽样上分解主生存 NLL、两单模态辅助生存
NLL、带原始 `lambda_recon_loss` 的重建目标。

**aux 精确复现校验：385 次重复中重建辅助与原生 aux 的最大绝对误差 5.96e-08**
（`torch.allclose(atol=1e-6, rtol=1e-5)` 强制校验，不通过即终止）。
分解因此可信，不是换了损失再出结论。

按患者先汇总 5 次 dropout 重复，再报告分布：

| 参数块 | 主 vs 辅助生存 | 主 vs 重建 | 辅助生存 vs 重建 |
|---|---|---|---|
| WSI 槽 | 中位 cos **+0.1267**（9/77 为负） | 中位 **-0.0237**（44/77 为负） | 中位 **-0.1437**（55/77 为负） |
| OMIC 槽 | 中位 cos **+0.4450**（4/77 为负） | 中位 **-0.0642**（54/77 为负） | 中位 **-0.0673**（55/77 为负） |

梯度范数中位：主生存 WSI 1.227 / OMIC 1.555；辅助生存 WSI 1.387 / OMIC 1.585；
**加权重建 WSI 0.000411 / OMIC 0.002509**。

**判定：机制证据部分支持。**

- 主目标与辅助生存目标在两个模态上**普遍同向**（负值仅 9/77 与 4/77），
  不支持"主/辅目标把共享槽推向相反方向"的强版本。
- 重建目标与两个生存目标**普遍反向**（55/77、54/77、55/77），但其梯度范数比主目标
  小 **3~4 个数量级**，且负余弦绝对值很小（|cos| < 0.15）。这是局部一阶取舍，
  按协议**不**自动证明长期训练冲突、内容无效或预测损害。
- 选槽器 `pred_keep_slot` 块：主生存与重建目标 `connected_parameters = 0`，
  辅助生存目标有连接。按协议这只算一个支路发现，不代替共享槽上的总体目标关系。

### P3 冷启动 —— 仅代理线索

原生随机初槽 vs 当前患者线索 vs 3 名错配训练患者线索，同权重同迭代预算。
指标为原生预算（10 轮）处到 30 轮共同参照的距离，越低越接近参照。

| 臂 | 中位距离 | 均值 |
|---|---|---|
| native_random | 4.222e-04 | 4.320e-04 |
| own_input_cues | 7.443e-05 | 8.363e-05 |
| mismatched_train_cues_0 | 7.538e-05 | 7.855e-05 |
| mismatched_train_cues_1 | 7.459e-05 | 7.497e-05 |
| mismatched_train_cues_2 | 1.119e-04 | 1.182e-04 |

逐患者比较：

- own 优于 native_random：**77/77**
- own 优于 mismatched_0：40/77
- own 优于 mismatched_1：31/77
- own 优于 mismatched_2：72/77

**判定：仅代理线索。** 协议要求支持"缺少患者线索造成聚合质量问题"必须**同时**满足
当前患者线索优于多个错配供体与随机臂，且在原生迭代预算下由独立内容标签支持。
本批只满足第一项的前半段（优于随机臂 77/77），与错配供体无差别（40/77、31/77
≈ 随机水平），且无独立内容标签。两条必要条件均不成立。

限定：这是推理期初态替换的条件反事实证据，**不是**训练后新初始化器的收益；
`reference_is_ground_truth = False`，长迭代末态只是参照，不是聚合真值。

### P4 语义不稳定 —— 同输入读取稳定性支持，语义结论缺条件

Hungarian 匹配读取内容后，报告匹配前/后距离、替代匹配间隔与匹配歧义。

| 指标 | WSI 中位 | OMIC 中位 |
|---|---|---|
| 匹配后距离（matched_mean_distance） | 0.000314 | 0.001951 |
| 匹配前距离（同索引配对） | 0.000779 | 0.002573 |
| 替代匹配间隔 | 9.79e-07 | — |
| 匹配歧义 | False | — |

匹配后距离小于匹配前，且替代匹配间隔极小、匹配不歧义。

**判定：仅支持"同输入的计算读取稳定性"。** 跨患者固定语义身份需要跨患者一致的外部概念
与支持，本次 `external_content_test` 为
`not_testable_missing_independent_content_labels`，**不**据此宣称 P4 已验证，
也**不**宣称"slot1 永远是某组织"。

### P1 固定容量 —— 冻结探针仅显示条件敏感性，容量因果未检验

冻结 checkpoint 下的槽数探针（未训练）：

| 槽数 K | WSI 有效秩 | WSI 槽对余弦 | OMIC 有效秩 | OMIC 槽对余弦 |
|---|---|---|---|---|
| 4 | 1.870 | 0.997532 | 2.548 | 0.995720 |
| 8 | 2.514 | 0.997843 | 4.797 | 0.996040 |
| 16 | 2.951 | 0.997942 | 7.343 | 0.996163 |

归一化分配熵在全部 K 下均为 1.000000（WSI）/ 0.999998（OMIC）。

有效秩随 K 上升但**远未接近 K**，槽对余弦基本不变，读取分配始终均匀。

**判定：仅报告冻结容量敏感性。** 协议要求的主要识别量是"容量 × 独立复杂度"的交互，
需要 capacity_train 匹配训练与**独立定义的**患者复杂度（人工区域/成分实例数）。
本次未启动 capacity_train，且无独立复杂度依据，因此**不**宣称患者事件容量不足，
**不**把 K16 均值优于 K8 当作需要自适应容量的证据。

`not_testable_missing_aligned_multiscale_or_multilayer_features`。
未用 Patch 重排、重复原特征或噪声伪造多尺度。

### P8 —— 原版不适用

原版 SlotSPE 无后续跨模态 OT，登记 `not_applicable`，未新增 OT 模块。

## 3. 总结

| 问题 | 判定 |
|---|---|
| P1 固定容量 | 冻结探针显示条件敏感性；容量因果与复杂度交互未检验（缺 capacity_train 与独立复杂度） |
| P2 冗余与碎片化 | **机制证据支持**（表示/读取冗余，跨 77 患者一致）；碎片化缺独立边界 |
| P3 冷启动 | **仅代理线索**（优于随机 77/77，与错配供体无差别，缺独立内容标签） |
| P4 语义不稳定 | 同输入读取稳定性支持；语义结论缺独立内容标签 |
| P5 无关内容干扰 | 缺条件不可检验 |
| P6 尺度与层次不足 | 缺条件不可检验 |
| P7 目标不一致 | **部分机制证据支持**：主/辅生存同向；重建与生存反向但范数小 3~4 个数量级 |
| P8 | 原版不适用 |

统一登记：**机制证据与预测损害分开。** 本批未把任何一项登记为预测损害；
过拟合、评估随机性、C-index 均不在本批主结果内。
