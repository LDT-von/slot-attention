SlotSPE 原始研究问题：实验识别审查
日期：2026-10-21
性质：实验设计审查；未读取患者数据，未执行模型、训练或诊断实验。

一、范围与判定原则

本审查围绕 P1 固定容量、P3 冷启动、P4 语义稳定性、P5 无关内容竞争、P6 尺度/层次、P7 目标关系。
评估随机性仅作为配对实验的控制条件；过拟合不充当上述问题的证据。

区分三层结论：
1. 原模型直接观察到的结构或表示现象。
2. 严格配对的输入/算法干预揭示的机制。
3. 匹配训练后对任务表现的影响及修正收益。
第一层不必等待第三层才能成立；但不能把第一层、第二层写成第三层。

公共实验约束：
- 冻结同一原始 checkpoint；每次配对共用模型随机抽样，而不只是设同一个随机种子。
- 输入扰动使用独立随机生成器，不能推进模型的随机流。
- 以患者为重复单位报告分布和配对效应；同一患者的多次抽样不能冒充独立患者。
- 保存实际干预前后输入预算、槽数、槽初值、选择结果及对照断言；私有明细留在 local_evidence/。
- 不因结果不显著就宣布问题不存在；缺条件时返回明确的不可识别状态。
- 任何阈值的来源必须写清：协议预设、训练集校准或人工定义；不能看完验证结果再挑阈值。

二、P1：固定槽容量与患者复杂度是否不适配

原假设：患者可区分内容的数量/分布有差异，而固定槽预算在复杂内容上出现容量不足，在简单内容上出现重复占槽。

最小可执行观察：
- 保持原模型 8 槽和输入 token 数不变。
- 有独立区域/内容标注时，测每种内容获得的槽覆盖、槽竞争、遗漏比例，并考察它们与内容复杂度的关系。
- 没有独立标注时，可测输入特征多样性、槽注意力覆盖和有效槽数，但输出必须标为“特征空间代理现象”。
- 多样性变化、有效槽数不变只是线索；高复杂度下独立内容覆盖下降才更接近容量不足。

配对机制检查：
- 构造已知来源成分数 M 的内容混合物；保持总 token 数、各成分取样规则、输入范数与模型随机抽样相同。
- 比较 M 增加时各已知来源的覆盖/遗漏曲线；以低 M 与高 M 为预设配对条件。
- 若来源由人工构造或 token 聚类产生，只能称“来源成分/特征簇”，不能称组织或病理异质性。

不得使用的捷径：
- 冻结一个按 8 槽训练的 checkpoint，推理时直接改 K，不能证明自适应容量优于固定容量；分布与归一化均已改变。
- 改 patch 数是在改采样预算，不是在改槽容量。
- 依据模型自身槽数计算“患者复杂度”，再据此论证槽数不合适，是循环定义。

必须另行训练才能回答的内容：
- 不同固定 K 或自适应 K 的任务收益；需匹配训练数据、训练预算、checkpoint 选择及下游读出。

保守 runner 结果状态：
- 有独立内容标注：content_coverage_assessed。
- 仅特征聚类：proxy_only，不自动输出 P1 confirmed。
- 没有可比较复杂度：not_identifiable_missing_complexity_reference。

三、P3：无患者内容的初始槽是否造成冷启动问题

原假设：初始槽没有当前患者信息，使有限迭代预算内的内容聚合不充分或产生错误竞争。

原模型可直接记录：
- 每轮 slot/attention/选槽轨迹。
- 各轮独立内容覆盖、来源混淆、有效槽占用及信息遗漏。
- 用独立内容参照判断“聚合好了没有”；不能把最后一轮槽当真值。

配对机制检查：
- A 原始初值；B 当前患者内容产生的初值；C 另一名患者产生、但统计尺度匹配的初值。
- B/C 采用相同构造方法、槽数、范数/方差约束，当前患者与供体患者仅在内容对应性上不同。
- 必须检查 B 是否仅因初值更大、更分散或更接近输入均值获得优势。
- 以达到预设独立内容覆盖标准所需的迭代数、固定迭代后的遗漏与混淆为主要读出。
- 每名患者多次原始初值用于测量稳定范围，随机性本身不作为研究结论。

解释边界：
- 在只见过原始初始化的 checkpoint 上更换 warm init 属于推理分布改变，只能提供干预线索。
- 要归因“患者特异初始化机制更有效”，需同训练协议的初始化方案对照。
- 轨迹变化小只表明收敛/稳定，不表明聚合正确；最终轮自一致性不能替代正确性。

保守 runner：默认只做原模型迭代轨迹与独立内容覆盖；缺内容参照时仅 trajectory_only。
暖启动臂应明确标记 exploratory_out_of_distribution，不能与原模型问题存在性混为同一判定。

四、P4：匹配内容后槽语义是否仍不稳定

原假设：等价内容在合理采样/初始化扰动下，无法形成稳定、可对应的槽表示。

正确比较单位：
- 槽集合和内容对应关系；不要求“第 3 号槽永远代表同一内容”。
- 槽编号置换是正常对称性，单独重排编号不能检验语义稳定性。

配对协议：
- 同患者两份独立 patch 子样本，或同输入多次共用/受控初值的重复。
- 使用固定外部内容锚点，或训练集拟合后冻结的特征原型；后者只代表特征语义代理。
- 用一部分 token/锚点完成 Hungarian 对齐；在未参与对齐的 token/锚点上评估语义一致性。
- 同时报告未匹配槽、分裂/合并率、每种内容跨重复的共聚关系；不能只报告被最优匹配抬高后的余弦。
- 加入标注/原型置换零假设，以及仅由有限 token 取样造成的不稳定参照。

关键陷阱：
- 用同一组槽余弦做匹配又做评分，会乐观高估稳定性。
- 每次重新聚类且把簇标签当固定语义，不能比较语义身份。
- 同患者的稳定不自动证明跨患者具有共同组织语义；跨患者需要可共享的外部内容定义。

保守 runner：允许特征原型匹配与 held-out token 验证，输出 feature_semantic_proxy。
无共享内容参照时，不输出组织语义稳定/不稳定的确认结论。

五、P5：无关内容是否抢占有效槽容量

原假设：对当前问题无关的内容进入竞争后，占用槽/注意力并挤压原有有效内容表示。

“无关”的定义必须独立：
- 背景、正常组织、低注意力 patch 不天然等于预后无关。
- 可用独立标注的扫描伪影、明确的构造干扰或具有已知任务关系的实验内容。
- 合成干扰只能证明机制反例；不能自动推广为真实患者内容无关。

配对协议：
- 固定一份基底内容，不删除或替换其中的有效 token。
- 两个条件加入相同数量的 token，保持预算一致：一组为预设干扰，一组为参考内容/重复内容对照。
- 另记纯预算变化对照，避免把总 token 数、softmax 分母变化全归为内容竞争。
- 用原有基底内容的覆盖、槽分配位移、来源混淆、被选择概率作为主要读出。
- 干扰注意力占比须同时报告干扰 token 占比；占 50% token 得到 50% attention 不等于异常抢占。
- 干扰与对照需说明范数、分布偏离和重复频次，避免只测到离群输入效应。

无效干预：
- 在未选槽之间洗牌，保留了集合与总和，不能检验未选内容有没有影响。
- 全零补位有自己的输入伪影，不能直接充当真实无关内容。
- 扰动臂是原赋值、空操作时，零差值不构成任何机制证据。

保守 runner：无独立无关性定义时只能称 controlled_distractor_competition，不能写“无关组织抢槽已确认”。

六、P6：单尺度/单层输入是否不足

原假设：单尺度或单编码层丢失对患者内容有用的互补信息，槽聚合无法从缺失的输入中恢复它。

必要输入：
- 同一患者、同一区域或可核对坐标的多倍率/多层特征。
- 编码器版本、特征归一化、坐标和视野范围记录。
- 变化的是倍率/层次，不能用 token 数、token 顺序或随机 patch 子样本替代。

可执行层次：
- 输入层面：使用训练集拟合、验证集冻结的内容探针，检验额外倍率/层是否提供单一输入没有的互补内容信息。
- 模型层面：单尺度/单层与配对多尺度/多层的匹配训练对照；输入预算、参数量与融合读出必须记录。
- 冻结单尺度模型直接接另一层特征，仅是在改输入分布，不能识别单尺度表示不足。

保守 runner 必须 fail closed：
- 仅有单倍率特征时返回 not_identifiable_missing_paired_scale_features。
- 仅有单编码层时返回 not_identifiable_missing_paired_layer_features。
- 不能悄悄改用 patch 数来输出 P6 结果。

七、P7：槽学习目标是否与预后任务不一致

两项不同问题：
A. 原训练目标的梯度是否到达应被监督的选择器/槽表示。
B. 同时存在的目标是否把表示推向与预后有用内容不同的方向。

A 的最小可执行证据：
- 同一前向图分别计算融合生存损失、辅助生存损失、重建损失及实际总目标对每个选择器/槽模块的梯度。
- 区分 None（图中未使用）、数值零、非零；给出模块级统计，不能把某一路 None 扩大成整个模型看不到任务。
- 保留各分量原损失权重；其他分支和前向选择必须相同。
- 这是梯度通路问题存在性的直接证据，不必先证明 C-index 下降。

B 的可执行检查：
- 在相同参数坐标上记录目标梯度的夹角、范数和加权实际贡献。
- 对同一小步长做分量方向的局部目标变化检查，可验证局部冲突是否真实体现为目标权衡。
- 梯度冲突本身是多目标训练的常见权衡，不能单独判定“目标错误”或预测损害。
- 若要主张偏离任务相关内容，需要独立内容参照或匹配训练消融；不能拿重建损失低当成任务有效。

保持前向相同的梯度干预：
- A 原始 self pool。
- B selected self pool 且最终选择权重梯度 detached。
- C 与 B 前向逐位相同，但最终选择权重梯度连通。
- B/C 除该梯度通路外的损失、辅助梯度、选槽、数值处理、eval 和训练折分箱必须一致。
- B/C 差异才能归因该梯度通路；A 与 B/C 同时改变了读出，不能全归因“修好梯度”。

保守 runner：先完成组件梯度通路矩阵与目标贡献；将通路缺陷、局部目标冲突、任务收益分开输出。

八、建议的首批执行顺序

1. 先核对可用 checkpoint、原始模块接口、是否可返回迭代 attention、是否有独立区域标签/多尺度特征。
2. P2 内容重复与 P4 匹配后的稳定性共用同一套 attention/锚点记录，减少重复前向。
3. P3 优先原模型有限迭代的内容覆盖；P5 优先已知来源的配对竞争反例。
4. P7 单个 checkpoint 的损失分量梯度通路矩阵，先复现局部结构问题。
5. P1 先输出复杂度与覆盖的证据层级，P6 缺配对特征则明确不可检验。
6. 不自动新增训练；任何患者前向/反向都由独立执行开关与授权控制。

本文件只审查识别，不表示以上实验已实施、已发现问题或已取得修正收益。

九、冻结容量与匹配训练容量的具体因子

冻结 checkpoint 的 K4/8/16：
- 因子是 inference_slot_count；训练槽数仍为 checkpoint 原来的 8。
- 返回 frozen_capacity_sensitivity，显示 K 改变时原模型如何响应；不能返回 capacity_mismatch_confirmed。
- 必须记录参数形状是否支持、每槽初值对应关系、选择 k 是固定还是随 K 变化、池化分母和下游读出。
- 若同时改 Top-K 选中数量，容量效应与选择稀疏度已混合；应另设清晰因子，不能暗改。

匹配训练 K4/8/16：
- 保持每个方案的 native 训练/推理槽数一致，匹配原始训练数据、split、seed 集合、优化器、更新次数、每步 token 预算和 checkpoint 规则。
- 报告参数量和实际计算量；更新次数匹配不代表计算成本相同，不要声称同时完成两种预算匹配。
- 优先采用 K × 内容复杂度的 3×若干层次设计。复杂度只能由独立标注或固定来源构造定义，不能由该次模型槽输出反推。
- 主要机制终点：每种内容覆盖、遗漏、每槽内容混合及冗余，而不是仅报告平均生存 C-index。
- 支持“固定容量不适配”的最小形态：复杂度较高时 K8 相对 K16 的独立内容遗漏更大，而复杂度较低时额外槽主要重复已有内容；报告完整曲线和不确定性。
- 若 K16 对全部复杂度同样有利，只支持较大容量有利，不支持“需要按患者自适应”。
- 如果 K4/8/16 整体表示均无差别，不得强行判定不存在容量问题；还需判断当前复杂度范围是否实际触及容量边界。
- 单 seed、小队列只作探索；不存在可以用推理敏感性代替匹配训练证据的捷径。

十、P4/P5/P6 的私有 annotation sidecar 最小字段

通用 envelope：
- schema_version、dataset_manifest_sha256、split_sha256、annotation_file_sha256。
- created_by/reviewer、evidence_document、annotation_method、review_status、ontology_version。
- 所有患者/切片/坐标逐项记录保存在 ignored local_evidence；公开收据只保留字段定义、计数和哈希。
- feature_file_sha256、feature_row_index 是 token 连接键；不能只靠读取顺序对齐。
- 标签必须独立于待测模型的 attention/输出；model_derived 标签只允许 proxy 标识。

P4 semantic annotations：
- anchor_id、content_class、label_source、confidence、roi_reference、matching_or_scoring_partition。
- label_source 可为独立 ROI 标注或训练集冻结原型，两者证据层级不同。
- 同一 anchor 不得既用于最优匹配又作为唯一语义评分依据；需要独立评分 partition 或独立属性。
- 仅有重复输入的 attention 匹配，返回 computational_stability；有独立内容标签才可返回 semantic_stability_assessed。

P5 nuisance annotations：
- role：anchor_signal / candidate_nuisance / relevant_control。
- role_scope：acquisition_artifact / non_target_content / prognostic_irrelevance_claim。
- role_evidence、reviewed_by、reviewed_at、independent_of_model、feature_origin、distribution_scope。
- acquisition_artifact 或 non_target_content 不能自动升级为 prognostic_irrelevance_claim。
- 人工确认组织为正常/背景，只确认组织类别，不确认它与预后无关。
- contrast_id、dose、base_token_indices、added_token_indices 明确基底内容没有被删掉，两个添加臂数量一致。
- 无预后无关性依据时，结果表述为“被预先定义的候选干扰竞争”，不能写“预后无关内容抢槽已证实”。

P6 paired features：
- pair_anchor_id、base_feature_file_sha256/row、paired_feature_file_sha256/row。
- 坐标系、中心坐标、物理视野范围、像素分辨率、倍率信息、裁剪规则。
- encoder_architecture、encoder_checkpoint_sha256、layer_id、feature_dimension、normalization。
- correspondence_kind：exact_region 或 same_center_different_context；后者的视野变化是明确实验因子。
- 维度或分布不符合原 checkpoint 输入契约时，不能补零/截断后强行前向；返回 incompatible_feature_contract，或使用独立内容探针。
- 没有真实 row/坐标对应关系的“同一患者两份特征”不足以识别尺度/层次效应。

十一、runner 决策矩阵

P1：有固定 K 源码 + 输入多样性 -> 结构事实及 proxy；有独立复杂度与内容覆盖 -> 容量相关现象；再加匹配训练 K × 复杂度交互 -> 容量不适配机制证据。
P3：无患者 cue 初值 -> 结构事实；有限迭代独立内容覆盖不足 -> 冷启动相关现象；匹配训练的 own-cue 优于 donor-cue -> 患者 cue 机制证据。
P4：仅槽编号变化 -> 不构成问题；匹配后 attention 不稳 -> 计算稳定性问题；独立内容评分仍不稳 -> 语义稳定性证据。
P5：任意内容扰动改变输出 -> 敏感性；预设 nuisance 抢占固定 anchor 覆盖，且剂量/预算对照通过 -> 特定干扰竞争证据；是否预后无关另按 role_scope 限定。
P6：仅 patch 数变化 -> 不回答 P6；有效配对特征的互补内容证据 -> 输入信息不足线索；匹配训练同任务对照 -> 模型/任务尺度效应。
P7：原生总目标中直接融合梯度 None、辅助梯度非零 -> 范围明确的通路缺陷；目标梯度相反 -> 局部权衡；匹配训练 B/C -> 该梯度通路的任务影响。

共有拒绝条件：原生回放不一致、forward 重建不一致、输入对齐不成立、matching/scoring 泄漏或 gate 来源不明确，均应 abort/不可识别，不能继续生成问题确认旗标。
