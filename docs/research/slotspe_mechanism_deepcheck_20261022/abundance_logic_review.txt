归一化与数量信息：数学反证及限定
日期：2026-10-22
范围：只读已有研究笔记；纯 Python 标准库 fractions 精确有理数计算。未探索或修改原版源码，未导入 torch，未读取患者数据、权重或运行模型。

直接结论
“槽更新没有单独输出 attention mass”成立；“因此整个 SlotSPE 必然看不见组织比例”不成立。后一说法有直接反例，不能登记为已确认缺陷。本轮没有把候选风险升级为患者发现。

1. 必须区分三种数量
（a）分配总量：一个槽在 token 轴上的原始 attention 权重总和。
（b）输入计数：本轮输入 token 的总数 N。
（c）内容比例：固定 N 时，某类 token 占多少。
三者不是同一变量。即使（a）未显式输出，也不能自动推出（b）（c）都不可恢复。patch 数量或 attention mass 也不是经过标定的组织面积、细胞数量或患者组织丰度。

2. 单槽归一化确有尺度歧义，但全体槽的约束可能携带信息
记槽竞争后的权重 A[k,i]，每个 token 满足 sum_k A[k,i]=1。
记 m[k]=sum_i(A[k,i]+eps)，R[k,i]=(A[k,i]+eps)/m[k]，更新 U[k]=sum_i R[k,i] V[i]。
单独看一个槽，在可实现范围内同时缩放 A[k,:]+eps 不改变 R[k,:] 和 U[k]，因此该更新没有直接输出 m[k]。
但全体槽同时满足 sum_k m[k] R[k,i]=1+K*eps。若 R 满行秩，这组方程可唯一确定 m。因此，“归一化使任何形式的 mass 信息都必然消失”过强。该恢复需要读取权重 R；下游只收到更新向量时未必具备同样条件。这也不反过来证明完整表示一定保留了 mass。

此前三槽两 token 的歧义构造复核成立：
R1=(0.8,0.2)，R2=(0.2,0.8)，R3=(0.5,0.5)；V1=(2,0)，V2=(0,2)。
两组基准 mass 为 (0.5,0.5,1) 与 (0.75,0.75,0.5)，实际 m 乘以 (1+3*eps)，A=mR-eps，eps=1e-8。
两组 A 均正且列和为1；更新均为 (1.6,0.4)、(0.4,1.6)、(1,1)，用有理数计算精确相等。
关键限定：R3=(R1+R2)/2，读取行线性相关，因而存在 mass 零空间；更新彼此不同不能排除这种线性依赖。三槽两 token 也天然不可能满行秩。
反例限定：只有 R1、R2 时行列式为0.6，m 唯一为 (1+2*eps,1+2*eps)，不能任意改变两槽 mass 又保持这两个读取行。
因此，这一构造证明“存在歧义”，没有证明实际 K=8、N=256 的读取矩阵必然具有同样歧义，更没有证明任一既有 checkpoint 达到该构造。

3. 完整复制所有 token：绝对计数不敏感，比例完全未变
把每一个 token 原样复制 r 次，且每份复制拥有相同 V 和相同槽竞争权重，则归一化前分子与分母都乘 r，U 精确不变。eps 同样逐 token 相加，结论仍成立。
本轮 r=3，使用上节两 token 的构造，有理数计算 U 精确相同。
若上游逐 token 编码、每步更新和随机状态均相同，类似不变性可逐迭代延续；本轮没有检验任何完整模型。
这个对照只说明整体复制的绝对基数不进入该归一化均值；它保持所有内容比例不变，不能用来证明“25%与75%的内容比例模型也分不清”。对固定256 patch协议，增加完全重复patch本来也不是新增独立组织证据；绝对计数不敏感未必是任务缺陷。

4. 固定 N 改变两类内容比例：明确反证“比例必然不可见”
两类 value 为 v_A、v_B，固定每类的槽竞争权重 a_A、a_B，令 w_A=a_A+eps>0、w_B=a_B+eps>0，B类比例为p：
u(p)=[(1-p)w_A v_A+p w_B v_B]/[(1-p)w_A+p w_B]。
du/dp=w_A*w_B*(v_B-v_A)/[(1-p)w_A+p w_B]^2。
只要两类 value 不相同，固定权重下改变比例一般会改变该槽更新。这里是对“一定不可见”的反证，并非完整迭代模型对所有输入都能正确测比例的保证。

最简单的精确反证：v_A=0、v_B=1，各 token 的两槽竞争权重都为0.5；N=100。
25个B时两槽更新都为0.25；75个B时都为0.75。均值本身直接携带比例。
可见槽冗余甚至可以与比例可见同时发生，两个问题不能混为一谈。

较强专门化情况下，比例敏感性可能很小，但仍不等于严格不可见：
两槽权重分别为 (a_A,a_B)=(0.999,0.001) 与 (0.001,0.999)，eps=1e-8。
N=100，B占10%时两槽更新：0.00011121107527567754、0.991071340171494。
B占90%时：0.008928659828505969、0.9998887889247243。
差约0.00881745，非零。下游可能放大或利用这些变化，不能只因变化小就判定信息缺失。
理想硬分配时，每类只进其专属槽，类内均值确实不随该类数量变化；标准正值软分配通常只接近这个极限，不能把极限结论直接套到实际模型。

5. 合理的后续诊断（仅设计，未执行）
第一组只改变 N：同比例整体复制，对照绝对基数不变性；不据此判定比例失败。
第二组固定 N：以独立内容标注构造类别比例扫描，保持每类内部特征分布、共同初态与随机流配对；先检查编码器输出是否已经可区分，再分别看逐迭代读取、更新、GRU后槽、最终融合表示。
第三组分开扫描 attention mass 与内容比例：两者不能用一张注意力热图互相替代。
评估槽的整体无序集合，允许槽置换；同时测可读出的比例信息、灵敏度和随机波动，不以单次严格相等或余弦相似为唯一判据。
患者结论需要真实且有定义的采样/面积标注；拼接合成 token 只能证明受控表征能力，不能直接证明患者组织丰度损失。训练对照和患者任务仍需独立执行授权。

推荐登记用语
“逐槽归一化没有显式保留分配总量；在特定分配结构下，内容更新存在总量歧义。固定 token 数的内容比例仍可能通过均值、泄漏分配、槽历史或其他路径被保留，完整模型是否弱化任务所需的占比信息尚待验证。”
不推荐：“SlotSPE只能知道是什么，不知道有多少”“已经证明组织丰度丢失”“复制不变就证明比例不可见”。
