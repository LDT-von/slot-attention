结论
WSI 原目标查询＋共享固定字典的构造反例有效，但只证明 WSI 重构头单项目标不强制槽承载当前样本的变化。不能称其为训练后真实槽的退化实证，也不能直接证明完整原版总目标可在无患者信息的槽上同时最优。
完整模型比例对照应保留为反证：原版整体可以响应比例变化，不能再写成“整个模型分不清有多少”。近同初态结果只支持随机网络中的十轮净差异收缩，不支持内容恢复失败。

一、共享固定字典反例：数学与实现有效
定位：脚本 reconstruction_dictionary_check。
冻结查询是方形线性映射 y=Mx+b。按脚本的 PyTorch Linear 权重约定，MHA 查询投影设为 M^-1、偏置设为 -M^-1 b，可以恢复目标 x。冻结映射自身未改，回执确认该项为真；矩阵条件数约1401，数值实验使用 float64。
两个保留的字典码0/7在每个头的三个坐标上为全负/全正，目标也仅使用这两个码。查询读到当前目标后，高增益 key 让注意力选择对应固定 value；输出无需字典随样本改变。字典内部有8个不同向量，输入目标的排列和比例可变，因此它不依赖“所有槽完全相同”的旧退化设定。
回执记录：两目标案例最大逐元素误差均0，余弦损失约 -2.22e-16；固定查询负控损失0.9375，全零槽负控损失1，均不恒等重构。这些控制表明目标内容查询和字典 value 都实际参与，不能把该反例写成“完全忽略槽的直接复制”。
有限 key gain=128 时，理想实数输出与目标间仍有指数级小的幅值差；每头正确/错误 key 的 logit 约为 ±67.88，输出约为 tanh(67.88)倍目标。余弦目标不惩罚该共同幅值差，因此反例对原生余弦损失仍成立。回执误差精确0是机器精度结果，不应声称有限参数在实数上逐元素严格恒等。

成立的最窄表述：
“WSI 重构查询含有当前目标内容；对两原型合成目标，原生重构头存在一组公开构造的有限参数，使跨样本不变的槽字典也得到近零重构损失。因此低 WSI 重构损失不能单独证明槽编码了当前样本的内容排列、比例或样本特异变化。”

必须同时保留的边界：
- 这里只构造重构头权重和手工提供的槽，不证明这些字典槽能由完整原生 SA 在当前训练协议中实际产生。
- 两原型、原型正负方向和人工逆映射/高 key 增益是已披露的存在性设定，不代表自然训练概率或任意连续病理特征。
- 跨样本相同的类型字典本身可能有意义；缺少样本特异变化不等于“槽没有任何语义”。
- 只覆盖 WSI 重构单项，不覆盖 OMIC/joint重构、生存损失或其总和；也没有证明患者预测损害。

二、完整模型比例、数量与置换对照：现有解释正确
定位：脚本 native_full_model_checks。
同模型、同 OMIC、固定32个WSI token、配对 RNG，只改两个原型的比例。A25%与A75%的最大 logit 差三个种子分别约0.22069、0.14236、0.15668，明显不同于置换/整袋复制的约1.7e-16至2.8e-16数值误差。
由此可以否定“整个原版模型对比例普遍不敏感”的强断言。它只表明存在响应能力，不能证明学到了正确的组织比例或有效预后效应。中间50%案例仅用于有限性检查，未记录可供检验单调性的输出，不能声称剂量反应单调。
整袋复制三倍保持组成，只改采样基数；与默认固定patch预算及组织相对占比不同。这里的不变性不是对固定patch协议的实证缺陷。配对置换是输入特征袋的顺序核查，不是原片空间几何测试。

三、新增几何控制：有明确外部真值，结论限于入口绑定
4×8网格的上下分区与棋盘格均含16个A、16个B；前者展开后正是 mixture[1]，后者是同一特征多重集的实际顺序改动，且32个特征入口值并非全同。网格共52条四邻接边，异类边分别为8和52；旋转90度后统计不变。外部邻接统计量确实区分两场景，旋转控制避免把绝对朝向当关系真值。
三个种子原版完整模型输出差约2.22e-16—3.33e-16，处于同袋置换舍入量级。这比只改未消费的 coords keyword 更有信息：给定明确关系真值，两种真实不同的网格绑定在独立patch特征袋接口下仍不可区分。
接受的表述是“入口只提供独立patch特征多重集时，模型不能从缺失的特征—空间绑定恢复这种邻接关系”。它是输入接口/排列不变性的条件能力边界，不是槽独有故障，也不外推空间上下文编码器、真实组织关系质量或患者预测损害。
邻接比由整数计数后的默认浮点除法得到，回执0.1538461596是8/52的浮点近似，宜正文直接写8/52和52/52。模型 float64 的声明不宜理解为所有外部诊断统计均以float64计算；此处不影响关系判定。

四、近同初始化：已修正零扰动比值，仍需限制归因
定位：脚本 near_equal_initialization_check；最新比值字段250行。
各 delta 使用同一权重、输入、共享噪声、扰动方向与 RNG，且记录实际捕获到的初末状态。除零扰动外，初态差异确实非零；正控覆盖了原生随机初态，控制较旧版更充分。
必须保留的报告口径：
1. 02版 delta=0 时，槽逐元素完全相等，但求均值的舍入产生约1e-16的 centered RMS，旧代码因只判断 widths[0]==0 而报告0.332—0.388的无意义“收缩比”。03版已按初始槽逐元素相等排除此比值，三个值均为null，并显式记录排除原因；修正有效，旧收据未改写。
2. 小扰动1e-4/1e-2的十轮末/初比约0.249—0.274；原生随机初态也收缩至0.141—0.207，delta=1也约0.169—0.213。不能将收缩特指为近同初态的额外故障，也不能证明训练造成槽坍缩。
3. seed29的小扰动轨迹个别中间轮略有扩张，宜写“十轮净收缩”，不能写“每轮都收缩”。
4. 绝对状态 RMS 收缩没有独立内容真值，也没有读取分配质量判定，不能改称“内容恢复失败”。尺度因子0.0625与按头维度参照0.125仅是设计对照；没有因果实验就不能判其为bug。
