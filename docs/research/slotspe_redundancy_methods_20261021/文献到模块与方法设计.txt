一、判断先行

有收获。最重要的共同点是：应改变槽形成时的内容分配，或去重后重新聚合；
训练结束后仅修改Top-K，无法反过来改变已经形成的槽。
当前本地71人历史模型的选中槽表示与读取均高度重叠，因此这一方向有具体问题入口。
但当前现象尚未证明唯一根因是平局，也没有证明MESH、DIAS或MetaSlot能修好SlotSPE。

可以模块化。本轮已经写出独立的“聚合内部内容分配”对照模块，保留原版源码、
相同投影/value、初槽、GRU/MLP、槽数与外部预测路径。新增自己的方法目前是下文的
可检验设计，并未冒称已经实现或有患者收益。没有启动训练、患者推理或新服务器任务。

二、8篇论文与7个源码包分别带来什么

1. DIAS：删槽后必须再读一次输入。
论文：Slot Attention with Re-Initialization and Self-Distillation，§3.2，PDF第4页；
Table 6/7，PDF第7页。https://arxiv.org/html/2507.23755v3
先用ia-1轮聚合，按槽余弦距离进行凝聚聚类，将冗余槽清零，再用mask执行额外一轮聚合。
被保留槽不再受删掉的槽竞争，然后才解码。不是随机重启所有槽。
COCO对象识别消融中，“删槽+重新聚合”top1/R2=0.70/0.63，仅删槽=0.68/0.62。
这是该图像任务的证据，不是生存预测增益。
本地DIAS-main.zip/readme.md第37行明确说没有公开slot pruning/re-initialization；
object_centric_bench/model/dias.py第105-110行只有一次aggregator调用后解码。
结论：概念高度相关，下载包不能直接充当完整论文实现。若重写，必须标成论文重实现。

2. MetaSlot：按原型识别重复，再在去重后的槽上重新聚合。
论文：§2.2-2.3，PDF第4页；Table 5，第10页。
https://arxiv.org/html/2505.20772v2
先聚合，再量化到全局codebook，同一prototype只留一次，再做第二阶段masked aggregation。
不是“低分槽删掉”，也不是“让全部槽向量正交”。最大候选数仍固定，动态的是有效mask。
同一COCO消融：去掉mask的FG-ARI/mBO/mIoU=38.2/28.5/26.9，完整=40.3/29.5/27.9。
本地metaslot.py第57-76行确有重复索引mask；第99-135行确有两阶段聚合；
第153-163行将无效槽在竞争logits中mask。还同时使用原型替换、噪声和梯度截断。
结论：是可借鉴的完整代码路线，但全局原型字典的代价和领域适配比MESH大；
同一病理/通路类型可以有不同状态，同prototype不等于同预后信息。

3. MESH：不在最后删槽，直接打破槽分配的平局。
论文：§3-4，PDF第3-4页；https://proceedings.mlr.press/v202/zhang23ba.html
相似槽可能反复得到相近更新；普通Sinkhorn多迭代也保留相同槽的对称性。
MESH给成本极小扰动，再用少量成本梯度更新降低Sinkhorn分配的熵，改变内容分配。
本地mesh.py第40-69行是熵下降，第46行是0.001噪声；slot_attention.py第158-181行
分别实现MESH和普通Sinkhorn，第183-186行保留原版归一化对照。
结论：最适合先做一个小而清楚的聚合内部模块；不能把普通Sinkhorn本身当作去冗余解。
均匀边缘、低熵也可能把同类组织任意切开，因此必须测value更新、内容和后续预测。

4. CoSA：以输入选择字典关联的槽先验，主要处理语义绑定和初始化。
本地src/model.py第293-313、357-403行确有条件量化初始化；qkcodebook.py第17-24行
mu/sigma是buffer、条目特异变换是Parameter。它不是简单的成对排斥损失。
可作为“患者线索初始化/语义锚定”的对照；对当前P2先不上完整字典体系。

5. PSA：带混合权重和方差的EM式槽推断，主要处理概率结构和可辨识性。
本地model.py第589-622行估计pi/sigma并构造aggregate posterior。
理论有分布、非退化和解码器假设，允许槽置换；不保证本项目槽数、语义或预后事件被识别。
不宜为了余弦下降而直接替换整个概率模型。

6. CODA：在扩散解码器条件序列后追加register，接收共享/残余注意力。
本地src/model/encoder.py第160-184行是在output_slots生成后追加register。
它不是上游Slot Attention内的去重模块，不能将它直接说成已解决SlotSPE的重复读取。
启发是保留共享信息出口，而不是把所有共有组织/基因信号都压掉；实际接入仍须另设计。

7. OCEBO：EMA教师和跨视图目标改善重构目标质量，主要处理学习目标。
本地models/ocebo.py第58-70行区分teacher backbone特征与student槽重构特征；
当前SlotSPE输入为离线特征，不宜为解决P2先引入完整图像预训练流水线。

8. 原始Slot Attention：提供竞争式读取、共享随机先验和置换性质的基线。
SlotSPE的models/slot_attention.py第90-100行先softmax槽轴，再归一化token轴。
模块接口必须放在这里，而不是把一个新损失堆在最终平均池化之后。

本轮重点重读/渲染了DIAS、MetaSlot、MESH的相关原PDF页，并重新读取7个ZIP的上述入口。
其余论文的详细理论核查沿用2026-10-20文献报告，本轮未将其全部理论重新证明。
15份PDF/ZIP实际重哈希均与本地登记一致。未安装、导入或执行任何下载ZIP中的代码。

三、已经实现的模块是什么

文件：survot_rank/research/slotspe_proof/assignment_router.py
SlotAssignmentRouter(logits[B,H,S,N], token_mask=..., noise=...) -> 读取权重[B,H,S,N]
replay_with_assignment(native, inputs, initial, router, noises=...) -> 每轮状态/注意力/最终槽。

三个明确分开的模式：
A original：逐元素复现原归一化。
B sinkhorn：固定均匀边缘的矩形Sinkhorn，作为“增加归一化迭代是否足够”的对照。
C mesh_uniform：固定均匀边缘的MESH式成本熵下降，作为破平局对照。

C是独立编写的适配版，不是作者完整SA-MESH复现：作者实现还学习input/slot marginals；
作者示例内层Sinkhorn常用5步，本原型默认20步；此处不带其图像编码器、解码器和训练目标。
模块无参数、无内部随机抽样；噪声由调用者显式给定，配对比较必须记录并复用。
保留全部候选槽，没有新增动态槽数或更改最终Top-K。原版生存/重构损失和预测头未接线改动。
fp16/bf16内层采用float32；支持torch.no_grad，局部成本熵下降仍需自动微分，
因此拒绝torch.inference_mode。训练保留最终分配对Q/K的梯度，不构建内层更新的Hessian。
不自动修改原模型forward、不注册持久hook、不进入现有训练/患者队列。

入口默认只打印计划：
python -B scripts/check_slotspe_assignment_router.py
只用生成张量的机制例子：
python -B scripts/check_slotspe_assignment_router.py --synthetic

合成例子：4个完全相同的槽、12个token、显式噪声seed11。
原版 / 普通Sinkhorn：读取重叠均为1.000，区分性value下更新cos均为1.000；
MESH适配：读取重叠0.622674，区分性value下更新cos=0.683056。
但当所有value相同时，三种方法的更新cos仍全部约为1.000。
这同时展示了能改变分配，以及改变分配不保证增加信息。不是训练后效果或患者证据。

四、自己的方法如何形成：候选设计，尚未实现/验证

建议研究问题：一个患者中，多个槽是在重复读取同一份可替代的预后证据，
还是在共享组织/通路上表达不同的预后状态？我们希望前者减少，后者可以保留。
目标是“条件互补的内容分配”，不是一律逼迫槽正交、争夺不相交patch，或最大化活跃数量。

最小候选：在MESH类的内部成本调整框架中，用“条件重复”替代无差别的熵最小化。
以下是待验证的公式草案，不是当前模块已经提供的mode。

1. 读取重叠 Oij = mean_head sum_token min(P_i, P_j)，P按token归一化。
2. 条件可替代性：固定其他槽和另一模态，用固定的下游读出h比较
   h(S) 与 h(S[j <- i])，并做反向替换。用完整时间bin logit向量，避免标量risk抵消差异。
   对称差 d_ij 用训练折估计的输出尺度归一化；它是计算敏感性代理，不是患者获益真值。
3. 任务条件重复 R_ij = O_ij * exp(-d_ij/tau)。相同读取但替换后预后输出不同的槽，
   不应仅凭高cos或高O就被强行排斥。R从停止梯度的读出估计，避免通过这一目标直接把读出压平。
4. 在原成本邻域里优化
   J(C') = sum_i<j stopgrad(R_ij) * O_ij(P(C')) + beta * ||C'-C||^2。
   P由同一内部归一化产生，使用显式小噪声处理精确平局，仍沿用原GRU/MLP继续聚合。
   第一版固定8槽和总10轮，不同时引入动态数量、全局codebook、跨模态OT或额外重构目标。

这是一条可做成模块的研究路线，但当前还不能称为已建立的新方法：
- 局部无预测差可能只是读出不敏感或模型欠拟合，不能直接视为无用槽；
  必须设置不可靠读出/常量读出的否定对照，并比较仅内容约束的版本。
- 干预是对同权重的计算代理，训练中可用冻结/EMA读出减少自我循环，但其额外开销必须计入。
- 首先应核对关键生物内容覆盖；token分配不同并不等于不同组织/通路、独立事件或因果机制。
- 基因通路具有交叠，病理的同一patch也可能同时携带多个因素，不强制两模态使用同一排斥强度。
- 如果后面需要重新分配/删槽，必须单独加臂检验；不能把多个步骤合在一起后归功于去冗余。

五、查重后的边界，避免把现有工作改名

除本地论文外，核对到两项相关的一手资料（本地无对应下载包，本轮未审计其实现）：
QASA：https://arxiv.org/html/2601.12936v2
已明确使用quality、coverage、novelty选择槽并配合gated decoder。
When Attention Collapses：https://arxiv.org/html/2605.02323v1
在加性混合任务中用剩余证据状态和attention bias，降低重复解释强信号。

因此“覆盖率+新信息选槽”“剩余证据/顺序扣除”“加共享register”“按原型去重”
本身都不能写作我们的原创。把这些拼在一起也不自动形成创新。
上面的任务条件重复分配只是候选差异，尚未做穷尽式查新；即使未找到同名，也不能据此宣称首次。
是否值得形成方法，取决于能否证明：对共享但互补的信息误删更少，对重复证据分配更少，
保留稀少内容，并在匹配协议下维持或改善下游任务。

六、下一步实验必须能拒绝这个想法（未执行）

先比较：原版内部归一化、普通Sinkhorn、MESH适配；同初槽、同输入、同外层10轮、
同候选数8、同Top-K、同初始化权重、同生存/重构损失、同patch抽样/训练分箱/评估规则。
内层成本优化增加计算量，固定外层轮数不等于固定FLOPs；必须另报耗时、显存和计算预算。
当前适配没有作者的学习边缘；结论只比较这些明确实现，不泛称优于论文完整方法。

再比较候选：仅O内容约束、O+条件可替代性R、完整候选。用相同预算并包含常量读出反例。
若实施DIAS重实现，将原总T拆成(T-1)+1，分别测仅去重与去重后再聚合；
动态mask对所有实际读出分支的作用必须明确，尤其SlotSPE的cross分支原本使用全部槽。
若实施MetaSlot，增加codebook/二阶段/噪声须各自归因，不能只称“去重模块”。

首要结果同时报告：逐轮读取重叠、value更新差异、中心化槽能量/有效秩、
可回查的内容覆盖、相同患者抽样的匹配后稳定性，以及最终/辅助预测分开的NLL与C-index。
使用训练折选定配置，再验收留出患者；不按验证患者结局逐个选槽。
只有cos下降：只能说明几何变化。
读取重叠下降但value/覆盖不变：可能只是把相同组织切成不同patch。
内容指标改善但下游无变化：可报告表征机制改善，不能报告预测收益。
内容或预后变差：记录失败，不能为了去重而删除真实共享信息。
