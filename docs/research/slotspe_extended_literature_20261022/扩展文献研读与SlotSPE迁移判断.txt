槽机制后续改进：问题、方法与 SlotSPE 的迁移判断
2026-10-22 | SlotSPE / SPE-08 | extended_literature_mechanism_mapping

一、结论

原8篇覆盖了不少重要问题，但不足以覆盖槽机制的改进谱系。本轮另外研读16篇相关工作的正文方法与关键实验/局限，补入初始化与迭代训练、分配总量（attention mass）信息、容量课程、显式属性解耦、多层输入和关系抽象等路线。它们不全是可替换SA的插件：SPOT涉及解码器/监督，OCRA主要改槽后推理，SSA主要用于机制分析。不能把16篇都登记为已经适用于SlotSPE的算法。

对当前项目最有价值的判断是：优先弄清槽在形成时为何重复读取、选择后是否需要重新组织内容，同时防止把“更不同”当作“更有用”。第二条值得单独检验的支线是，归一化更新是否缺少内容占用比例。这里的“总量”指权重的和，不是分配好坏。初始化/动态槽数/语义锚定/几何/关系是不同候选原因或目标，不宜同时堆进一个版本。

文献支持某种失败机制有可能出现，不等于SlotSPE已经发生；SlotSPE出现某种机制现象，也不等于损害预测。此报告没有运行任何模型、患者实验或新修正模块。

二、先固定“槽应代表什么”

自然图像对象发现常以一个实例对应一个槽为目标；SlotSPE说的是潜在预后事件，两者不能直接等同。
例如，同一患者多个位置的淋巴细胞可能共同反映一个免疫状态；同一patch的肿瘤/免疫成分也可能参与多个事件。多个通路还可以共享基因。强制输入唯一归属、槽面积均衡或所有槽正交，可能破坏合理共享。

因此必须分别定义：
1. 槽是局部组织区域、全片组织类型、连续形态状态、通路模块，还是潜在预后事件？
2. 两槽的共同内容是重复读取、合理共用上下文，还是同类型的不同实例？
3. 需要去掉的是染色/批次等干扰，还是应保留的浸润密度、肿瘤量、结构位置？
4. 哪些内容有独立标签/审核依据，哪些只能测表示和读取？不能用当前模型自己的分配直接当生物真值。

三、新增16篇按“改哪一层”排列

精确题名、年份、全文URL、节页及限定条件见 literature_index.json 和本目录4份逐篇笔记。以下为整合判断，不能代替原文条件。

【初态与迭代怎样训练】
1. BO-QSA，ICLR 2023：可学习初查询与双层优化/直通梯度，处理随机竞争与训练困难。它是数据集层先验，不等于本患者条件初始化。查询训练方式与替换随机初态必须分开对照。
2. Object Representations as Fixed Points / Implicit Slot Attention，NeurIPS 2022：把槽迭代看作内层求解，用近似隐式梯度训练，缓解长反传的稳定性/资源问题；不是通过换求导就保证语义分工。
3. SmoothSA，ICML 2026（本轮读arXiv v5）：用输入条件preheater温启动，以自蒸馏训练；视频另区分首帧与后续帧更新。对静态SlotSPE相关的是温启动支路。其stop-gradient设计提醒我们“每条梯度都接通”不是通用正确原则。

迁移判断：SlotSPE当前共享高斯初态确实不读当前患者，因而有同类输入条件；尚未证明这就是读取重复的根因。共享可学查询、输入聚类查询、条件预热分别是不同控制。更多迭代、较稳定轨迹、同输入重复性好都不自动等于内容正确。

【输入先验、容量与形成粒度】
4. Clustering-based Slot Initialization（CSI），BMVC 2023：从输入特征聚类得到初槽，直接提供样本线索。聚类结果受特征可分性、核宽及候选中心等影响，不是无上限、免调参的对象计数器。
5. AdaSlot，CVPR 2024：在Kmax候选中作二元选择，以重建与槽数代价平衡有效容量。它不是固定比例Top-K。作者也报告删槽会漏掉小对象，且背景处理仍有限。
6. SlotCurri，CVPR 2026：从少槽开始，按重建误差总量复制/扰动槽并逐步扩容，结构损失帮助保留边界。它主要是训练课程，不是逐患者自由选择槽数。小对象混合仍是局限；高重建误差也不等于高预后价值。
7. COCA，CVPR 2025：以紧凑层次聚类改变分组路线。主实验的固定输出槽数与额外动态槽数消融要分开，不能把整篇说成无限动态容量。空间紧凑性对跨全片重复模式或通路没有天然依据。
8. FASA，2025-12预印本：两阶段前景/背景建模和伪mask监督，明确控制竞争角色。图像角点前景假设、MaskCut和图像布局不能移植成“病理间质都是背景”。共享预后上下文也不是应删除的无关内容。

迁移判断：原版SlotSPE有8个候选、按给定比例固定保留数量的机制；这一源码事实不能证明患者需要的容量已被满足或不足。动态保留数量、训练期间扩容、形成后去重、去重后再聚合，是四件不同的事。删得更少/更干净都要同时检查稀有内容召回。

【分配后的更新到底保留什么】
9. Attention Normalization Impacts Cardinality Generalization in Slot Attention，TMLR 2024：指出weighted mean的更新没有一般办法恢复槽获得的分配总量，提出有尺度的weighted sum/batch scaling。这是原8篇没有清楚覆盖的信息维度。
10. Understanding Clustering in Slot Attention via Particle Dynamics，2026-10预印本：用SSA隔离竞争式点积与weighted mean，另用USSA作理论分析。它主要提供机制拆解参照；移除第二归一化的USSA又出现活槽减少，不能推出所有归一化都应删除。

以单头、忽略eps的记号说明（仅公式推导，没有执行实验）：
  a_ki = softmax_over_slots(score_ki)
  m_k  = sum_i a_ki
  u_k  = sum_i a_ki v_i / m_k
u_k表达加权内容均值；同一槽整行权重的共同尺度会被除掉。m_k/N是另一种信息。由此只能说该步更新没有显式保留分配总量，不能推断整个递归模型在所有输入上都不能间接编码丰度。

SlotSPE在每头都做该类归一化。可把“内容均值+占用比例”列为诊断对象，与论文scaled-sum分别命名。当前多头压缩维数、后续混头与GRU历史并不完全满足论文单头命题条件；不能把定理直接套成全模型结论。WSI的m/N受真实patch抽样影响；通路的分配总量不是细胞丰度。保留总量也可能偏向常见大结构而压低稀有事件，须单独验收。

【学习目标、语义与属性】
11. SPOT，CVPR 2024：自回归解码器的patch顺序置换使其更依赖槽，用教师decoder注意力监督student encoder注意力。这里的decoder顺序不是SlotSPE输入bag的顺序；SlotSPE也没有相同的AR解码器。
12. Explicitly Disentangled Representations in Object-Centric Learning（DISA），TMLR 2025：分开形状、纹理、位置与尺度，并检查信息在哪些子空间泄漏。“分出对象”仍不等于属性可解释，更不等于统计可辨识性。其原始图像双流不能从压缩特征中凭空恢复已丢信息。
13. PathoSlot，MICCAI 2026：临床概念条件初始化、槽-概念一致性和端点监督，把共享WSI/报告证据分配到标志物与生存端点。正文明确区分预定义端点分配与独立临床因子发现，因而不能当作SlotSPE潜在事件发现的直接升级。

迁移判断：SlotSPE已有生存与重建目标，不是完全没有任务监督；但是这些目标不直接提供每槽的生物概念真值。主辅梯度同向也没有回答这件事。教师注意力、概念prompt、稳定槽匹配都需要内容有效性依据。若没有可靠标签，只能承认语义承载未识别；不能自行命名几个槽后就宣称获得可解释预后事件。

SPOT附录提供一个实际迁移反例：B.4/Table 9把BO-QSA用于DINOSAUR和SlotDiffusion，COCO instance mBO分别从32.3降到31.5、30.5降到29.5。它只证明这两个已测配方未获益，不证明BO-QSA在SlotSPE无效；但足以反对“知名槽模块一定通用提升”。

【几何、多层信息与关系】
14. Invariant Slot Attention（ISA），ICML 2023：让位置/尺度等变、外观相对不变，用槽相对坐标改变attention和decoder。它需要可用几何信息；稳定的位置捷径不是类型语义。作者也报告某些设置过分割增多，严格不变性有输入特征条件。
15. MUFASA，CVPR 2026：同一编码器的多个层分别做SA、按mask匹配再融合，利用深度上的互补信息。层深不等于病理物理倍率；已有单层缓存不能凭空变成多层。作者仍报告同类实例合并、一对一跨层匹配受限。
16. OCRA / Systematic Visual Reasoning through Object-Centric Relational Abstraction，NeurIPS 2023：把对象表征转换为关系瓶颈再推理。它主要是槽后关系读出，不是修改SA竞争以修复混槽。真实世界分组、容量与全对复杂度仍是限制。

迁移判断：SlotSPE已有槽内/跨模态后置交互，不能登记为“没有关系模块”；应问压缩之前是否保留了所需关系。现有forward没有显式接收全局patch坐标/邻接。几何若不在输入中，后加槽间attention不会自动补出真实邻接。对于全片多峰组织类型槽，一个质心也不足以概括布局。

四、把原八篇与新文献接起来，而非替换原编号

P1 固定容量：候选上限、每患者有效槽数、训练阶段槽数、复杂度需求分开。AdaSlot/SlotCurri/CSI/COCA提供不同控制。
P2 内容分工：重复覆盖、碎片化、混槽、遗漏、趋同后恢复分别记。MESH改竞争分配；DIAS/MetaSlot侧重去重后再聚合；SlotCurri从学习路径防碎片化。更新中的总量信息是另一条机制维度，不硬塞进“余弦过高”。
P3 冷启动：共享随机先验、共享可学查询、输入条件初始化分别比较；初始化质量与后续恢复能力分开。
P4 语义：运行重复性、类型绑定、属性解耦、统计可辨识性分开。槽编号固定不是统一要求。
P5 无关内容：前景/背景/共享上下文的角色须由任务决定。病理免疫或间质不能按自然图像经验删掉。
P6 层次：物理倍率、编码器层、部件/整体是不同变量，空间几何另列。MUFASA已在本轮补读；MSF仍未登记全文精读。
P7 目标：梯度关系、优化稳定、目标信息质量、槽承载的任务内容都要分开。SPOT/OCEBO/CODA/PathoSlot作用位置不同。
P8 双阶段OT：原版仍不适用；本轮不加入transport或DCT模块。

继续横列三个维度：输入可分性与信息边界；空间几何；关系与组合。另把“更新的分配总量信息”和“迭代求导/收敛性质”作为跨项机制记录，不另造已确证的P9/P10。

六、值得优先研究的顺序

优先一：内容分配与选择后恢复，直接承接已有重复读取观察。
先区分重复是否已经出现在竞争权重、token归一化、value更新、混头、GRU还是最后读出。按头、按迭代追踪，避免只看最终余弦或头平均图。再分别设置“原版形成后直接用”“同样选择后继续读取”“聚合内部改变分配”的匹配对照；前者与DIAS式再聚合不能混称同一修改。额外迭代须有相同总迭代/计算预算控制。

优先二：内容均值与分配总量是否需要分别保存。
由归一化论文导出的新诊断对象。先问同类模式占比变化是否能被现有表示识别，再决定试scaled-sum或显式占用量旁路。需要真实抽样合同与可信内容定义，不能用“更新带总量”直接宣称保留预后信息。

优先三：若初态导致错误分配，就比较输入条件初始化；若内容承载错误，就核对目标或语义约束。
SmoothSA/CSI与BO-QSA是有用对照；不能把输入条件优势预先当真。概念监督只在有可验证概念/标签时进入。没有标签时保留未识别状态。

条件支线：动态容量须有复杂度/召回证据；几何须有坐标及应保留的空间命题；多层须有同patch对齐特征；关系须有可观测关系。缺输入信息时不要先加关系网络。

可检验的问题表述（研究提案，未证明）：
“在从多模态输入形成潜在预后事件时，能否减少重复读取，同时保持稀有内容覆盖、合理共享和结构关系，并使保留下来的槽承载可核对的任务信息？”
这比“让槽之间余弦更低”更接近目标，但仍需明确内容单位，逐项选择可证伪子问题。不能把这句话本身登记为创新成立。

七、最小判别框架（仅研究设计，不是执行授权）

A. 重复与碎片化/混槽/遗漏联合验收：有独立mask/标签时，分别检查内容召回、每内容对应槽数、每槽对应内容数；SlotCurri的OIR/DOF/DUF提供参考，但具体阈值与计数定义不同，不能互换。没有标签时只报告读取重叠和生成反例，不伪造生物真值。
B. 恢复验收：比较选前、选后直接用、同总迭代的选后重聚合；看新内容是否回来，而非只看有效槽数减少。
C. 信息验收：内容均值与占用量、局部类型与空间布局、共享上下文与独特内容分别检验。稳定/可分/可解释/有效预测不是同一个指标。
D. 收益验收：先表征与内容，再冻结权重干预，最后才是同协议训练对照。自然图像ARI、合成反例、包测试和单checkpoint均不能替代患者泛化。
E. 后续实现须保持原源码快照和既有A/B/C归因合同；初态、投影、value、迭代预算、槽数、选择规则、数值处理、评估随机流、训练折分箱分别固定或明确列因子。不要把工程梯度修正与研究模块合并归功。本轮不改任何默认队列。
