一、Adaptive Slot Attention: Object Discovery with Dynamic Slot Number
简称：AdaSlot；CVPR 2024。
作者：Ke Fan, Zechen Bai, Tianjun Xiao, Tong He, Max Horn, Yanwei Fu, Francesco Locatello, Zheng Zhang。
一手全文：https://arxiv.org/pdf/2406.09196
HTML：https://arxiv.org/html/2406.09196
作者项目：https://kfan21.github.io/AdaSlot/
本次原件：local_evidence/literature_20261022/adaslot_2406.09196.pdf，21页。
SHA256：cbc8b162a809c7011d826304118e4181f20885ce516666659d098c6f7b6b5fc7
阅读：正文方法/实验，附录A、C–E、K；重点PDF第3–4、6–8、11、13–17页。

作者真正指出的问题：固定槽数不能反映样本复杂度，槽太少容易欠分割，太多容易过分割。固定Top-K也仍要求事先确定保留数。它首先讨论容量与样本需求失配；不是把槽向量余弦相似作为唯一问题。
改动：先用普通Slot Attention形成Kmax个候选槽；每槽MLP输出保留/丢弃概率，借mean-field把2^K子集选择分解为K个二元决策，使用straight-through Gumbel-Softmax。目标是期望重建误差加lambda乘期望保留槽数。删槽发生在重建读出端，不能把它称为对内部竞争的直接修正。
关键实现边界：第4页式(11)让被删槽的alpha混合mask精确归零并对保留mask重归一。只把槽向量置零/换成可学习mask向量，经过decoder后仍可能产生非零alpha并进入分母。附录E第13–15页的消融显示这一差别非常大。这里有一个能迁移的检查问题：选槽在每条使用槽的路径上究竟删除了什么，剩余归一化是否仍含被删内容？这只是检查问题，不能据该论文认定SlotSPE存在同一种decoder缺陷。
不能省略的条件/反例：
1. Kmax仍是上限；附录第14、17页显示上限变化会影响指标。不是无限容量、不是彻底免选槽数。
2. mean-field决策在选择步骤显式忽略槽间联合关系，作者仅认为可由上游竞争间接表达（第3–4页）。不能说它解决了槽间关系建模。
3. 第11页附录A：主实验从先训练200k步的固定Kmax模型初始化，再训练AdaSlot。直接从头插入需另做公平训练对照。
4. 第11页附录C：没有专门背景槽，可能把阴影/背景并到最近前景，牺牲定位IoU；不是所有背景都应删。
5. 第16–17页附录K：比同Kmax固定槽模型输出更少mask时，会漏掉更多小物体；真实场景part–whole层次仍困难。
6. 第7页COCO结果：最优固定槽DINOSAUR ARI 41.89，AdaSlot 39.00；不能概括成对最优固定槽始终更优。
对应目录：P1为主；涉及P2的碎片化/遗漏权衡、P7正则目标与梯度可达；不支持P8。
迁移SlotSPE的适用问题：若先证明病人间所需有效模式数变化且固定保留数形成瓶颈，可比较可变保留数与同平均容量的固定数对照。要保留原生任务损失与A/B/C的区别，另检查主任务是否能训练保留概率，以及重建支路与预测支路究竟各使用哪些槽。动态删槽不能重建已丢失或已混进保留槽的内容；不能替代DIAS式重新聚合检查。
预期风险：病理少量但有预后信息的区域可能被低重建贡献/稀疏正则淘汰；“样本视觉复杂度”不等于“预后信息复杂度”。应把罕见内容覆盖率、保留数与性能分开评价，不能只报删槽更多或余弦更低。
建议优先级：中。适合容量对照与选择语义核查；不应在现有重复读取原因未明时优先再堆一个门控。

二、Enhancing Interpretable Object Abstraction via Clustering-based Slot Initialization
简称：本文记CSI；BMVC 2023；本次所读arXiv长稿首页标A PREPRINT，不混淆出版排版。
作者：Ning Gao, Bernard Hohmann, Gerhard Neumann。
一手全文：https://arxiv.org/pdf/2308.11369
HTML：https://arxiv.org/html/2308.11369v1
BMVC官方：https://papers.bmvc2023.org/0471.pdf （本轮直连失败，未下载该出版版）
作者页面：https://gaobaoding.github.io/publication/bmvc23/
本次原件：local_evidence/literature_20261022/csi_2308.11369.pdf，21页。
SHA256：75e72fbdee2f496ebc620768c8e33035af44e797d0963adedb312e29ae85e16f
阅读：正文1–5节、附录A及失败图；重点PDF第2–3、5–8、11–15页。

作者真正指出的问题：输入无关的随机槽初态使后续迭代从不合适的位置开始，限制准确度；固定槽数也限制泛化。问题是初始化是否使用当前输入以及映射是否尊重集合对称性，不等同于让同号槽跨患者始终对应同一语义。
改动：先在感知特征上聚类，再映射为初槽；比较三类映射：(i)把固定数cluster flatten后MLP映射到固定K槽，非置换对称；(ii)Pseudoweights用槽位置编码和cluster的加权和，使输出对cluster顺序不变；(iii)mean-shift得到可变cluster，逐cluster共享MLP映射，使槽对cluster置换等变。
关键边界：第3页明确mean-shift核带宽sigma决定粒度，特征空间必须能形成可区分的mode。第14页附录不是无参数聚类：实际从20个中心开始，收敛后用epsilon连通分量合并；sigma/epsilon按初始网络权重调到输出不会恒等于1或20。因此“动态槽数”不等于无候选限制、免超参数。
作者的反例很重要：第7页Figure 5，某些k-means/Pseudoweights变体学成固定空间区域，而不是对象；重建变好并不自动得到所需对象分工。第8页还承认mean-shift的中间张量内存大，硬件不足而未在uORF验证mean-shift版本。正文第5页表1也存在某些映射比原版更差，不可只说“加聚类都有效”。
对应目录：P3初始化为主、P1与P4集合对称性；补输入可分性。它没有证明统计可辨识，更没有要求跨患者固定槽编号。
迁移SlotSPE的适用问题：若当前同患者输入条件初态不能稳定优于匹配的错配供体条件，应先分析特征聚类是否包含有意义信息以及原生迭代是否抹平初态；不能凭它就宣布P3已被证实。最小可比思路是固定K、相同迭代/预算，只替换初态为输入聚类中心经共享映射的初态；先和固定学到的query及随机初态比较，避免同时改变容量和初始化。
预期风险：WSI特征按染色、纹理或背景聚类，通路特征按幅值聚类，均不保证对应预后事件。高相似槽可能是后续更新/值投影造成，初态分开也会再次趋同。输入条件聚类能否迁移必须以内容读出与迭代轨迹判断，不能只比初槽间距离。
建议优先级：中高的诊断对照，低成本机制候选；前提是先审清本仓库P3已有观察及输入可分性。不要把mean-shift整套直接当作低成本首选。

三、Hierarchical Compact Clustering Attention (COCA) for Unsupervised Object-Centric Learning
简称：COCA；CVPR 2025。
作者：Can Küçüksözen, Yücel Yemez。
一手全文：https://arxiv.org/pdf/2505.02071
HTML：https://arxiv.org/html/2505.02071
CVPR：https://openaccess.thecvf.com/content/CVPR2025/html/Kucuksozen_Hierarchical_Compact_Clustering_Attention_COCA_for_Unsupervised_Object-Centric_Learning_CVPR_2025_paper.html
作者页面：https://cankucuksozen.github.io/COCA/
本次原件：local_evidence/literature_20261022/coca_2505.02071.pdf，24页。
SHA256：2ac0627443f60f76b33e046ebd5c2da5ab228330b54fcbcb9fbfe962d3259c53
阅读：正文第2–5节、补充6–7节及9.1、9.3；重点PDF第3–8、12–14、17–18页。

作者真正指出的问题：平行槽的routing/tie-breaking、预定数量、背景处理和对初始种子的敏感性；传统软k-means式结构还难处理不规则簇/异常点。这里把“对象是什么”补成一个具体的空间先验，而非仅要求槽互不相似。
改动：用COCA层替换SA式聚合；先局部self-attention细化节点特征、划分不重叠窗口、生成每个候选anchor的affinity mask；按质量归一的转动惯量测空间紧凑度，顺序选择高紧凑度anchor，把已解释节点从scope中遮掉，减少后续重复；聚类后池化特征/面积/质量/惯量/位置到下一层，逐层形成dendrogram。
与普通“多层SA”的区别：层次在输入到簇的显式归属树里，不是叠两层就有语义层次；顺序遮蔽针对已经解释的内容，不能等同于在槽向量上施加余弦正交。
不能省略的条件/局限：
1. 空间紧凑性先验明确使用原图位置、面积/质量、moment of inertia（第5页），不能用任意token编号充当空间位置。
2. 主实验第6页实际固定输出槽数为数据最大对象数；动态COCA-Net-Dyna是第8页单独扩展，停止条件取决于剩余scope。不能说主表全是动态槽数实验。
3. 主实验证据来自6个合成图像数据集；第17–18页真实Birds/Flowers是初步实验，单seed，不是病理证据。
4. 第8页作者承认自底向上缺乏top-down反馈，早期误合并无法纠正；紧凑度的成对密度比较有较大内存需求。
5. ShapeStacks包含背景的ARI并非最佳（第7–8页），背景定义/标注粒度会改变评价，不能把“更多连贯背景块”直接认定为更好的任务语义。
对应目录：P1/P2/P5；补空间几何、层次归属、恢复失败。它不等同于P6的倍率或预提取层特征，也不支持P8。
迁移SlotSPE的适用问题：若病理端真实坐标可用，并且研究问题明确关心连通组织区域/局部结构，可把紧凑性和层次覆盖作为诊断参照。全套COCA涉及编码器、局部窗口、聚类/池化和decoder契约，属于结构改造，不能当成轻量替换softmax。通路端不存在相同的二维紧凑物体假设，需要独立的生物关系图依据。某个组织类型可能分散在全WSI；强求空间紧凑会把同类区域拆碎，正与减少碎片化的目标相冲突。
建议优先级：暂后。先确认真实空间位置是否进入模型及目标是区域实例还是散布的模式；可用于完善空间/层次问题目录，当前不建议直接上全套。

四、Unsupervised Structural Scene Decomposition via Foreground-Aware Slot Attention with Pseudo-Mask Guidance
简称：FASA；2025-12-02 arXiv预印本；本轮未核实有正式录用，不登记为顶会论文。
作者：Huankun Sheng, Ming Li, Yixiang Wei, Yeying Fan, Yu-Hui Wen, Tieliang Gong, Yong-Jin Liu。
一手全文：https://arxiv.org/pdf/2512.02685
HTML：https://arxiv.org/html/2512.02685v1
本次原件：local_evidence/literature_20261022/fasa_2512.02685.pdf，17页。
SHA256：ed8e9238c7f935dd91d2282213e8e96f8748cf72db82ad39afda0b36e8d7ab2e
阅读：正文第3–5节、附录A及B.4/B.8；重点PDF第4–8、10–12、14–15页；局限起于正文结尾并在附录展开。

作者真正指出的问题：前景/背景不加区别地竞争，使背景干扰实例分解；固定多槽在前景对象少时会拆碎同一对象。两种问题并不等于槽重复，因此单纯增加排斥未必有效。
改动：第一阶段用输入特征聚类初始化的2槽分前景/背景；训练后冻结。第二阶段用新的K个槽，以attention-logit mask把第一槽专门分配背景，其余只竞争前景；MaskCut从DINO patch affinity graph生成伪mask，经Hungarian匹配后用BCE约束attention，另保留特征重建。附录第10页明确第二阶段仍从可学习高斯随机采样，不能称两阶段全都聚类初始化。
迁移边界中最关键的三点：
1. 第4页通过“前景应占据少于2个图像角”的先验判定两组谁是前景；第10页MaskCut也使用图像角先验。WSI中肿瘤/间质/免疫区域可遍布边角，随机抽patch没有四角布局，基因通路更无四角。不能原封不动搬来定义生物前景。
2. 第11页B.4：lambda太大时前景槽数坍到伪mask对象数，MaskCut固定3轮会把内容约束变成容量瓶颈、造成欠分割；不是伪标签越强越好。第12页表S4也有明显退化。
3. 第14–15页失败案例：密集相似对象仍会合并，极小对象在第一阶段就被吸入背景；输入特征混合、缺显式边界/几何/遮挡关系是作者承认的残留问题。第一阶段冻结后，错误前景定义会传递到后续阶段。
对应目录：P2碎片化/遗漏/P5/P7内容约束与目标质量；补输入可分性与空间前提。不用于支持P8双阶段OT冲突。
迁移SlotSPE的适用问题：可以迁移“先定义不应与目标模式混在一起的内容角色”和“用独立、可靠的内容约束验证分工”的研究思路；需要先界定哪些病理/基因内容确实可视为干扰，不能把间质或免疫微环境默认当无关背景。若没有可靠组织标签/空间结构/预后事件定义，单加background slot只会把问题变成未经证实的先验。
建议优先级：作为P5与P7内容监督的证据框架有价值；直接移植优先级低。尤其不宜用自然图像伪mask替代病理生物学标签。

横向结论（本分支）
1. 新论文确实增加了与原8篇不同的机制抓手，但它们分别改容量、初态、分组几何、内容监督，不能按“减少槽相似度”归成同一种修复。
2. 对当前SlotSPE主线，CSI更适合做固定预算下的初态诊断；AdaSlot更适合厘清固定Top-K与真正动态容量以及删槽路径；COCA、FASA更适合补问题定义和迁移前提。不能因为论文较新而优先改动更多结构。
3. 若保留槽高度相似且读取相同，优先问内部竞争/值更新在何处失去分工。已经混合的槽交给更聪明的删槽器，未必能恢复内容。若结构被拆碎，增强槽间排斥可能进一步恶化；若稀有内容遗漏，强稀疏正则可能再删掉它。
4. 应分别登记：源文机制事实；SlotSPE源码是否具备该触发条件；现有观察是否支持；新诊断需什么标签/坐标；修复是否改善分工；分工改善是否提高外部/交叉验证预测。后一层不能由前一层代替。
