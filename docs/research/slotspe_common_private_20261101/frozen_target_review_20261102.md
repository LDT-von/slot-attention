# 撤掉已知角色后的内容目标：验收结果与研究决策

2026-11-02；父提交 `6ad3aab`。本阶段是具体进展：新增冻结目标工具，完成12组目标适配、30次新合成训练、数学反例与回执核查。不是患者结果，也不是原版 SlotSPE/V2 的训练对照。

**决定：不将未经任务核对的冻结PCA目标加入主网络。**它可以构造可复现的辅助内容标签，却不能自行决定什么是预后有益内容。保留该工具作正负诊断；下一步先修正当前共有/私有研究原型的共享通路约束，避免只优化私有分支。

## 1. 本次实际实现

`FrozenPrototypeTargets` 只接收训练输入和有效token mask：在预先指定的观测描述子空间中做患者等权k-means++；每个原型按患者计算其他观测特征均值，拟合第一主成分及训练中位数，得到逐原型二元内容目标。中心、标准化、PCA方向、均值与阈值随后全部冻结。标签不含生存时间/删失状态，也不来自学生输出。

无类型one-hot输入；token顺序逐患者随机打乱。缺失原型记为未知，不作为负目标、不排除患者；NaN填充不进入拟合或目标。长袋不会因token更多而增加患者在原型拟合中的总权重。工具没有患者加载器、队列入口或默认真实特征路径。

该方案仍假设存在**预先指定的描述/内容子空间**。合成数据的两个描述坐标有可区分的类中心，其余坐标含患者内容、共有量和噪声。这不是无假设的语义发现，更不是临床UNI特征的已验收适配器。固定聚类编号只定义字典身份，不证明生物过程分工。

目标侧有硬聚类，但只用来生成辅助监督；生存读出仍使用全部槽的均值，没有预测时选择/Top-K/注意力门控。默认网络形状不变，本次仍为每模态4个16维槽、4维共享向量、每槽4维私有变量的小模型。

## 3. 30次固定对照

所有臂均开启每槽1 nat软预算、权重.3；内容权重为1（仅预算臂为0）。五臂：仅预算、已知真实内容上界、冻结内容、训练患者错配的冻结内容、常量目标。上界臂明确使用生成真值；冻结臂只用观测输入。错配只作用于训练监督；留出评分使用正确冻结目标，不能称为未见患者的随机标签恢复率。

## 4. 数学反例改变了下一步

`frozen_target_counterexamples_receipt.json` 保存三个精确构造：

1. 两个独立比特A、B，固定目标及私有变量T=V=B。目标熵ln2、内容误差0，但对任务Y=A的信息为0；改成Y=B则有用。同一输入分布的无监督目标不能保证任意任务效用。
2. G恒定且目标B必须无误恢复时，若还要无误保留独立任务A，需要至少2ln2 nat的输入信息。试验上限1 nat不足以同时无损保留两者；软经验预算本身不构成总体上限。
3. 若内容目标T=G且解码器只看V，完美内容恢复反而要求V携带至少H(G)的共有信息。因此强内容监督可能主动制造共有复制；不能仅靠标准化和私有预算声称去重。

另对**当前独立CommonPrivateSurvival研究原型**构造重新编码反例（不是原版SlotSPE源码缺陷的结论）：

\[
c_w=(S,\epsilon P,0),\quad c_o=(S,0,\epsilon Q),\quad
G=(S,\epsilon P/2,\epsilon Q/2).
\]

若P、Q独立、方差1，对齐MSE为`2 epsilon²`，而读取权重`(0,2/epsilon,4/epsilon)`能从G准确恢复`P+2Q`。对齐误差趋近0不排除G携带完整私有内容。交叉预测的不可预测部分也不会因这些被忽略的小通道必然增大。原型没有限制读出权重范数；这是允许的表示构造，**不是已训练模型采取该路径的证明**。

`shared_path_leakage_receipt.json` 在四个epsilon值上精确复核。它解释为什么只对V做漂亮的内容/容量改进，仍不足以得到可信的共有/独有语义。

## 5. 下一架构审查：把共有通路也纳入同一信息瓶颈

优先审查的候选保持双模态槽、私有容量与全槽均值读出，替换当前无约束确定性G。每模态只由自身输入产生共享高斯后验`q(C_w|X_w)`、`q(C_o|X_o)`，以另一模态可构造的密度为条件参照。对固定网络、正规密度及Markov条件`C_w−X_w−X_o`，

\[
E\,KL(q(C_w|X_w)\|r(C_w|X_o))
=I(C_w;X_w|X_o)+E_{X_o}KL(q(C_w|X_o)\|r(C_w|X_o)).
\]

候选最简版本以另一模态的共享后验作为r，双向计算该KL；不增加患者负样本估计器。它约束不能由另一模态解释的共享编码，**与旧的给定G约束私有U的条件KL是不同的变量和用途**。这仍是标准变分条件信息界，不是新定理，也不识别所有预后有用共有因素。

生存预测必须经过实际随机C样本；若偷偷使用无噪声均值作共享旁路，信息界不覆盖实际读出。拟保留原cross预测项、全模型生存项及逐槽私有预算，不把本次PCA目标加入主损失。确切权重和实现需先通过数学/梯度及已知答案门槛，当前未实现、未训练这个新候选。

必须先验收：共有信息恢复、私有任务不被G伪装吸收、常量共享坍缩、共享无关量、XOR协同、随机样本/均值旁路差异。共享KL可因常量后验降为0；跨模态可预测内容也可能是站点偏差，因此不能把该界或跨模态一致性直接等同于有益共有信息。删失生存NLL针对观测事件过程，不能无条件解释成真实生存时间互信息；本合成数据采用独立删失，真实数据还需审查条件独立与支持范围。

归因顺序：在同一高斯共享架构中比较共享KL开/关与私有预算开/关，再以旧确定性G作架构参照。原版/V2患者对齐仍是另一个问题；该新研究候选不复用不匹配的旧患者分数。反塌缩与读出替换继续独立，不增加服务器臂。
