# 多因素内容与信息预算的数学前置审查

本轮用可枚举总体审查下一步目标，没有训练任何网络。**决定：先研究现有私有信息预算的阈值下行为；暂不增加逐槽内容头、以任务标签为条件的总相关惩罚，或直接最大化删槽损失差。**这不是新方法已成功的结论，也不把下面的标准信息分解作为原创定理。

## 1. 当前rate是否已经涉及槽间重复

令A为一个患者的全部模态输入，G为实际共有随机样本，V为该患者的全部私有槽。每槽是同一患者内的随机变量，不是一个独立患者。固定网络参数和总体分布，假设参考密度覆盖编码密度的支持、相关期望有限，并且实际私有采样在给定(A,G)后逐槽独立：

`q(V|A,G) = product_k q_k(V_k|A,G)`。

对于当前归一化槽的rate，参考`r_k=N(0,I)`，有

`R_sum = E sum_k KL(q_k(V_k|A,G)||r_k)`

`= I(A;V|G) + TC(V|G) + sum_k E_G KL(q(V_k|G)||r_k)`。

这是KL链式分解。**总体总rate已将任务相关增量、槽间条件总相关、条件边际与参考的失配混在一起收费**；它不是纯粹的重复度，也不保证优先删除有害因素。因此现在再增加一个高维TC估计器，不能直接称为弥补“完全没有重复约束”。

一般条件相关后验还需减去`E TC(V|A,G)`；当前代码的独立高斯基础噪声满足产品后验假设。反例中若四槽共享同一个纯噪声比特，单槽rate全为0，聚合槽TC却为3ln2，恰被后验TC修正项抵消。不能在任意相关采样下省略假设。

这里是固定参数下的总体数值恒等式。训练中是小批量期望近似，G停止梯度且编码器共享；不能把一个正则梯度等同于纯TC梯度，更不能由经验KL降低证明真实TC降低。此处也不是原V1 KL、V2 HSIC和本研究rate之间的等同声明。

源码事实：`shared_private_objective`当前实际惩罚是`mean relu(batch_mean(R_k)-c)`，c=1 nat。**当某批槽均值严格低于c时，该槽预算项对rate的梯度为0。**总体均值低于c不意味着所有批次均不激活。本轮没有测量既有训练中的激活比例，不把平顶区直接认定为历史失败原因。

例如两槽分别用rate=.5的高斯码重复同一个因素，或只用一个同码、另一个为N0，预算惩罚都可为0，总rate却为1与.5。这说明平顶区不继续区分容量内的重复；重复也可能提供降噪收益，不能把所有重复观测都称作无效。

## 2. 可计算的多因素任务及九种反例

总体有五个独立公平比特：共有S、WSI的P0/P1、组学的Q0/Q1。每模态两个槽，每个枚举行是一个完整的假想患者状态，共32种；噪声编码另枚举编码随机性，最多512行。没有抽样估计、训练/验证患者或患者数组。

四个生存bin的hazard分别依赖P0/P1/Q0/Q1及S，采用独立删失bin分布(.1,.1,.1,.7)。每个私有因素对某个hazard是必要的；不再用一个标量风险因子验收全部槽。观测内容目标为`T_k=sign(S)+2 sign(P_k)`（Q类似），是特权已知答案，不是实际WSI目标适配器。

给定每种表示，在精确总体上计算最优条件内容MSE、条件熵及删失生存NLL。生存控制混合的是事件概率与存活分布，不能平均hazard。最佳每模态单槽是已知总体的oracle，不是用测试集选择有限探针的许可。所得生存NLL不能与先前神经任务或患者C-index比较。

| 各槽保存一个因素 | 0 | 0 | 1.11752 | 1.23232 |

因子编码的全槽相对最佳单槽降低NLL .11480；复制患者信息时差为0。新仪器因而具有区分这两种已知情况的总体分辨率，尚未证明有限训练的探针或模型有同样能力。

**先验区别必须保留：**表中rate用每种已知分布的精确聚合边际q(V_k)作参考，仅为oracle分解检查，绝不是把该数值当成当前神经N0先验KL。四因素理想码的oracle总rate=4ln2，复制码=8ln2；集中到一个槽仍为4ln2。即使总rate压缩能抑制额外复制，也不强迫所有槽活跃。固定N0还需支付额外聚合边际失配，不能直接移植这些数值或容量阈值。

## 3. 拒绝或收紧的三个目标

**逐槽内容头。**问题 → 希望每槽保留可解释内容。方法作用 → 要求`d_k(G,V_k)`单独恢复T_k。可检验预测 → 每槽都应有对应因素。对照 → 模态内协同码。结果解释 → 该码完整保留所有因素、预测与理想码相同，但逐槽MSE为2，联合MSE为0。因此硬性的逐槽目标会误伤允许的有用协同。联合内容目标可作保留诊断，但它同时允许复制和集中，不能自己保证互补。若将来明确要求可单槽解释，需承认这是额外假设和取舍。

**以任务为条件的TC。**对独立P0/P1、任务Y=P0 XOR P1，`TC(P0,P1|G)=0`，而`TC(P0,P1|G,Y)=ln2`。后者惩罚掉的是有用协同引起的条件依赖，不能将它命名为应去除的无效重复。未来患者标签还受删失影响，更不能把观测标签条件TC直接解释为真实生存信息。

**最大化删槽增量。**理想`sum_k I(Y;V_k|G,V_-k)`不是一般可加的信息分配：XOR中全槽任务信息ln2，两个删槽增量之和为2ln2。更危险的是直接优化`L_full-lambda*(L_minus-L_full)`：若一个可读取mask的解码器故意将缺槽分支的真标签概率降为exp(-M)，私有码可保持常量，目标却随M趋于负无穷。lambda=.1、M=100时目标约−9.23754，内容并未增加。若对缺槽基线停止梯度，在无hinge的这个简单式子中只是将full梯度乘1+lambda，并没有自动产生去复制作用。理想信息诊断仍可用；将有限解码器差直接作为训练奖励需要额外的内层最优化与校准，本轮不实现。

## 4. 共有噪声与语义不可识别

当G=S时，`V_k=P_k`与`V_k=P_k XOR G`拥有相同联合内容误差、任务预测和rate；后一编码单独看私有槽无法预测P_k，但给定G可精确恢复。即使TC为0、条件内容完美，也不能由此识别单槽生物学语义。

若`G=S XOR N`且N服从Bernoulli(.25)，共有目标仍有`H(S|G)=.56234 nat`。令私有V=N，则`I(G;V)=I(S;V)=0`，但`H(S|G,V)=0`。此时私有分支只是在纠正共有噪声，并没有原先定义的模态私有因素。条件内容/预测的正增量可以有价值，却不能自动叫“生物学独有信息”。

## 5. 推荐的下一最小消融：预算内收费

当前更值得审查的是平顶预算，而不是再加一个MI估计器。保留当前网络、随机共有通路和全槽均值读出，只比较一个预算函数族：

`phi_eta(R)=eta*R+(1-eta)*relu(R-c)`。

eta=0精确回到当前平顶预算；eta=1为连续rate；eta=.1为预先固定的中间控制。在R<c时斜率eta，在R>c时斜率1，因而eta=.1与原预算在阈值以上的斜率相同，主要隔离阈值下收费。这是普通的分段线性正则消融，**不是新MI估计器、原创定理或已成功的方法贡献**。

建议后续锁定24次合成训练：两任务（四因素分时hazard、四因素跨模态XOR hazard）×3个新数据/训练seed653/677/701×4臂（无私有预算、eta0、eta.1、eta1）。每臂500步Adam .003、batch32；共有rate权重.1、观测均值cross权重.1、私有权重.3、c=1不变。均为每模态2槽、width16、共有/私有维数4、4时间bin，不是患者8槽配置或4096 patch。

合成训练512行，token袋16行/模态；观测中有两类固定type metadata、共有量与私有因素的带噪测量、独立无关量，无潜在风险标签作为网络输入。拟用新随机命名空间810000起，与旧任务隔离。拟保留192/128/384行probe-fit/validation/test；最佳单槽或探针只在validation选择，test固定评分。诊断真实因素是特权评估，不加入内容训练损失。此设置的type假设不能迁移为临床语义。

四臂使用相同初始化、数据、批次及共享/私有噪声；固定末500步checkpoint，不按验证挑epoch或eta。每个模型5次随机前向分别评分，是24次训练而非120次。预算为12000次CPU核心更新、2线程；实际墙钟尚未测量，不报告虚构GPU耗时。**本轮没有实现此目标函数、生成神经任务或执行这24次训练。**

必须同时记录：原始/平均每槽rate、预算激活批次比例、梯度与非有限事件、均值/随机槽几何、任务因素与无关量的有限探针、全槽相对验证选定单槽的内容增量，以及生存NLL。不能以rate或秩单独成功。连续收费也可能删掉有用因素、降低分数或诱导集中，失败要保留。三种子仍是探索，若要选模型还需新的确认；本计划不把测试结果用于反复改eta。

## 6. 原论文、实现与本轮证据等级

- [beta-TCVAE原论文](https://arxiv.org/abs/1802.04942)与[作者vae_quant.py](https://github.com/rtqichen/beta-tcvae/blob/master/vae_quant.py)：已分开总体信息、TC及边际先验失配；官方代码使用聚合联合与聚合边际的log-density差。本轮把它写成患者级槽分组、给定G的条件分解，是标准恒等式的应用，没有创造该原理，也未移植其小批量TC估计器。
- [Locatello等ICML2019](https://proceedings.mlr.press/v97/locatello19a.html)：语义识别需要明确归纳偏置。其一般无监督边界不直接证明所有监督生存网络不可识别；本轮的条件XOR重编码是针对当前目标的具体反例。
- [DisentangledSSL原论文，2025版](https://arxiv.org/html/2410.23996v2)与[作者实现](https://github.com/uhlerlab/DisentangledSSL)：共有/特有的覆盖与分离本已有明确问题和假设。本轮未复现其全部训练，不能把本预算消融包装成该问题的完整新解法。

16项有限分布测试通过，九种编码rate恒等式的最大数值残差2.71e−14，另有XOR、共有噪声、解码器作弊及平顶预算控制。数值由声明总体精确求和到浮点误差，不是患者或小样本MI估计。主网络源文件仅只读核对；第三方、历史回执、运行队列不修改。患者训练、患者推理、患者checkpoint读取、神经训练和优化更新全部为0。本轮产物：`finite_content_audit.py`、检查脚本、计划、原始聚合回执、此审查与验证凭据；状态统一登记在`docs/PROGRESS.json`。
