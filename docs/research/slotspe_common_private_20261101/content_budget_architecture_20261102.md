# 固定内容目标与每槽信息预算：架构、数学和本地验收

2026-11-02。独立研究分支 `codex/common-private-mechanism-review`，父提交 `abed03b`。本阶段结论是：**固定内容监督能在已知角色的合成数据中形成内容差异；信息预算能限制编码量，但两者都不能保证生存预测改善。保留全槽均值为当前读出，角色拼接只作对照。**

## 研究决策与完整网络

当前选择一条主线：内容目标约束下的每槽变分信息预算。直接 vCLUB 留作历史对照，不继续叠加一个依赖估计器；独立反塌缩干预不混入该实现。这里的“共有/独有”仍是操作性分支，尚未识别出真实生物学共有/独有因素。

| 层 | 默认形状/作用 | 本阶段小模型 |
|---|---|---|
| 冻结输入 | WSI 与组学 token，训练折预处理；本原型没有患者加载器 | 每模态12个8维合成 token |
| 两个 SlotEncoder | 每模态8个128维原始槽，3轮竞争注意力和 GRU 更新 | 每模态4个16维槽 |
| 共享分支 | 各自槽均值投影到32维，`G=(c_w+c_o)/2`；对齐与跨模态均值预测 | G为4维 |
| 随机槽分支 | 每个原始槽与 `sg(G)` 输入对角高斯后验；条件先验只见 `sg(G)` | 每槽4维 |
| 标准化 | `V_mk=(U_mk−mu_prior(G))/sigma_prior(G)`，与固定标准正态计算逐槽 rate | 槽数保持4/模态 |
| 内容头 | 每模态一个跨槽共享 MLP，仅见 V，不见 G、角色编号或事件标签 | 预测固定类型内观测数值的正负 |
| 主读出 | `z_m=mean_k phi_m(V_mk+e_mk)`；`head([G,z_w,z_o])`输出4个时间箱 logits | 所有槽参与，无预测 Top-K/注意力权重 |
| 读出对照 | 固定角色顺序拼接全部 V，再经容量匹配 MLP | 与主读出共享其余初始化 |

默认仍是 **WSI 8槽＋组学8槽，共16槽**，另外有一个32维共享向量 G。不是每模态再额外产生8个共有槽；U与V是一组槽的两套坐标，也不重复计算槽数。本地验收使用4＋4槽，不代表已验收默认大模型。`e_mk` 是患者无关的学习常量，零初始化，不是动态门控。

内容标签仅参与训练损失，不作为预测输入。合成 token 的前4维提供精确类型身份；该身份固定了“第k槽应保留什么”。这属于有利的已知角色条件，尚未建立对应的真实病理目标。实际分配仍由 Slot Attention 学习，并非按标签硬切 token。

本实现也不是在原版 SlotSPE 的原生预测通路上加残差：它是独立研究网络，没有原版未改动 logits 的旁路。不能拿这里的数字归因于原生信息保留，更不能替代原版/V2患者对齐实验。

## 损失和梯度

令 A 为一名合成患者的整对输入袋，不把同一患者的K槽当成K名独立患者。

\[
R_{mk}=E_A KL(q(V_{mk}|A)\|N(0,I)),\quad
L_T=\operatorname{mean}_{i,m}\frac{\sum_k M_{imk}\,BCE(d_m(V_{imk}),T_{imk})}{\max(1,\sum_kM_{imk})}.
\]

\[
L=L_{surv}+.1L_{cross}+.1L_{align}
 +\lambda_T L_T+\lambda_B\operatorname{mean}_{m,k}[\widehat R_{mk}-C]_+.
\]

本阶段固定 `lambda_T=1, lambda_B=.3, C=1 nat/槽`，关闭旧的总 KL beta 项；这些是探索点，不是最优参数。预算项是小批量经验均值的软 hinge，既不限制每名患者的瞬时 rate，也不是总体容量上限证书。缺失内容目标是未知，不作为负标签；所有本次合成角色均存在。

- 生存损失经预测头回传到G与所有V、phi及角色常量；竞争注意力发生在槽构造阶段，预测读出没有选择权重。
- 内容损失/预算经V回传到后验、条件先验、原始槽和编码器。`sg(G)` 阻断到共享摘要分支的直接梯度；共享的槽编码器参数仍会变化，不能称为完全隔离。
- 内容目标函数已冻结、不可求导；内容头不见角色编号，避免仅靠槽编号预测患者内容。平衡目标和独立探针仍是必要检查，结构本身不能排除其他捷径。
- 标准化在条件先验坐标中移除可预测均值/尺度，不等于证明私有槽与G独立。所有条件高斯先验/后验对数方差均沿用 `[-8,4]` 截断。

## 互信息含义与证明边界

对固定训练后的网络，在总体分布上有标准变分恒等式

\[
R_k=I(A;V_k)+KL(q(V_k)\|N(0,I))\ge I(A;V_k).
\]

若T_k、G是A的确定函数、T_k离散且熵有限，并令CE为预测T_k的正规概率解码器的总体交叉熵，则

\[
I(A;V_k\mid T_k,G)\le R_k-H(T_k\mid G)+CE(T_k\mid V_k,G).
\]

证明：`I(A;V|G)=I(T;V|G)+I(A;V|T,G)`；左项不大于`I(A;V)`，而`I(T;V|G)=H(T|G)−H(T|V,G)`，条件熵不大于正规解码器的CE。本内容头只见V，故其CE也是上述条件熵的一个较松上界；另有 `I(T;V) >= H(T)−CE(T|V)`。

这说明：**在固定目标可恢复、容量接近目标所需信息量时，额外编码空间受到限制。**它没有证明预算1 nat适合真实患者，没有把CE当成熵的下界，也没有保证槽间互信息下降。总体目标熵和条件熵在真实数据中未知；有限训练/测试的KL、CE不能直接代入后宣称得到高概率互信息证书。对缺失目标需在同一条件分布上重新推导，当前patient等权mask损失并非该证明的自动实现。

若完整随机槽条件独立且采用乘积标准先验，逐槽rate之和还分解为整组输入信息、聚合后验总相关及各边缘先验失配。减少总rate可能同时删除有用信息。这里不单独最小化所有槽对的依赖，以免直接禁止有用协同或共享目标。

数学验收保留7个有限分布：最小目标、复制无关内容、无信息编码、先验失配、目标已含于G、重叠目标和XOR目标。特别是 `T=G` 时，擅自把`H(T|G)`换为`H(T)`会给出错误界。常量/纯噪声可低rate，但不能同时恢复平衡目标；复制患者全部信息可低内容误差，却消耗额外rate；把信息重新编码到G能绕过私有预算，当前共享约束不足以排除该退化。已有非线性副本、纯噪声、常量与删槽仪器反例继续有效。

## 已完成的72次合成训练

两批均为CPU、小网络、每臂500次Adam更新、512名合成训练样本、batch32、lr=.003、固定末步，无最优checkpoint选择。独立探针fit/validation/test为192/128/384；核族只用validation选择。五次随机前向平均NLL不是五次训练。

## 与已有工作的边界

- [Deep VIB](https://arxiv.org/abs/1612.00410)已建立变分信息压缩；上述rate恒等式和链式推导不是新定理。这里研究固定槽内容的保留/压缩及全槽利用条件。
- [PIBD论文](https://arxiv.org/abs/2401.01646)及[官方模型](https://github.com/zylbuaa/PIBD/blob/main/models/model_PIBD.py)已有模态内压缩、共有/特有分解；源码PIB含Top-K实例提取，PID的[CLUB实现](https://github.com/zylbuaa/PIBD/blob/main/models/club.py)约束模态分支依赖。因此“共有/独有＋互信息＋预后”不构成新贡献。当前区别是固定内容目标的槽级预算和无选择读出，但是否具有实质增益仍待验证。
- [Grounded Object-Centric Learning](https://proceedings.iclr.cc/paper_files/paper/2024/hash/ba4caa85ecdcafbf9102ab8ec384182d-Abstract-Conference.html)已研究稳定槽类型与字典；本阶段直接使用合成角色监督，不能将槽身份稳定称为首创。官方仓库尚未核对到可固定版本的实现，本阶段不声称已复现。
- [DeCUR论文](https://www.ecva.net/papers/eccv_2024/papers_ECCV/html/4236_ECCV_2024_paper.php)及[官方仓库](https://github.com/zhu-xlab/DeCUR)研究共有/独有与冗余约束；本轮核对论文/仓库，未复现其训练。
- [DisentangledSSL论文](https://arxiv.org/html/2410.23996v2)与[官方仓库](https://github.com/uhlerlab/DisentangledSSL)讨论共享/特有信息最优条件及不可达情形。本文不以强独立约束假定所有共有信息都能无损移走。
- [DIMAF](https://arxiv.org/html/2503.16069v1)和[MurreNet](https://arxiv.org/html/2507.04891v1)均已针对多模态预后做共有/特有处理；本轮核对原文，未确认官方实现，不给出复现结论。仍需更系统核对近期邻近工作，不能保证全球新颖性。
