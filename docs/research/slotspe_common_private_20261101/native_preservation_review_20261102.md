# V2 原生信息保留与依赖代理的源码／数学审查

日期：2026-11-02；基点：`cb3f89a80d9f37d3165aaca37730b32efe6e09d5`。本轮只有源码审查、已知答案构造和梯度单元验收；新增神经训练、优化器更新、患者执行和服务器操作均为零。推荐下一步研究有范数界的原槽残差，尚未把它接入网络或升级为默认方案。

## 本轮决定及与已有研究的关系

上轮24次多因素合成训练没有支持加强私有rate收费：采样内容减少，未得到稳定预测收益，XOR任务仍未解决。停止该收费族的扫描。本轮回到更靠前的问题：V2是否在施加解耦约束之前，已通过重新编码改变甚至丢失原槽信息？

答案是：**在完整槽张量空间，当前V2接口确有不可逆方向；在真实患者流形及真实生存头上是否造成损害，仍未证明。** 同时，当前HSIC作用的汇总可以完全漏掉私有槽中保存的一比特共享信息。加普通残差能保住原接口的某些零空间方向，却仍可能制造新的抵消。不能把“加skip”“低HSIC”或“64+192=256”写成无损语义解耦的证据。

这些结果约束设计，并未形成已证实有效的新患者网络。研究原型`CrossmodalSharedBottleneck`与历史`SharedPrivateSlots` V2是不同实现；本轮没有把前者的训练结果冒充后者的效果。

## 1. 源码事实：当前V2替换了什么

以列向量写，省略模态及患者下标：

\[
C=A_s\bar S+b_s,\quad U_k=A_uS_k+b_u,\quad
F(S)_k=P_sC+P_uU_k=M\bar S+NS_k+b,
\]

其中M=P_sA_s，N=P_uA_u。L=F(S)，槽数仍是每模态8个，不是变成1个共享槽加8个独立患者。C是每模态内部、跨槽平均后的一份表示。两套模态参数既不共享也无该处的跨模态对齐损失，不能直接称其为“跨模态生物学共有”。

梯度从预测头经L、两个projection、两个encoder回到原生S；内容项只经内容头／U／私有encoder回到S；HSIC经C及私有矩汇总两路回到S。批内标准化统计没有detach。不存在“私有有害因而直接删掉”的源码保证。

原版`third_party/SlotSPE/models/SlotSPE.py:283–332`先取得原槽与Top-K门控，全部槽仍进入cross_attention；两个intra支路用门控mask，最后拼接cross均值和两模态intra均值。未选槽仍有跨模态预测路径，训练还有辅助解码／重建。评估主预测在本接口之后没有另一个原始token直达logit的旁路；训练重建目标、第二次OMIC槽调用仍存在，不能把接口碰撞扩大为整个训练过程完全无信息。

## 2. 维度相加并不意味着槽集合无损

把K个槽分成一个均值和K−1个独立对比方向。预编码(C,U_1,…,U_K)的线性秩恰为

\[
(K-1)\operatorname{rank}(A_u)+
\operatorname{rank}\!\begin{bmatrix}A_s\\A_u\end{bmatrix}.
\]

原因是所有槽对比方向只走A_u，而均值方向走堆叠的A_s、A_u。输出L的秩同理为

\[
(K-1)\operatorname{rank}(N)+\operatorname{rank}(M+N).
\]

默认K=8、D=256、p=192、c=64，预编码秩至多1600，输入ambient维度2048，**至少448个线性方向不能区分**。这在任意参数值下成立；训练只能改变被保留的子空间，不能突破此结构上界。这里448是完整连续槽张量空间的维度，不是448比特，不是448种患者特征，也不是已观察到的临床损害。

两个默认初始化种子731／105460实测秩均1600。反向控制：若真实数据只在所有S_k相同的低维流形上，M+N可满秩；两个初始化的该均值映射秩均256，解析恢复误差分别3.62e−12、3.83e−11。因此不能由ambient零空间断言患者流形必然受损，也不能说增加有效秩必然改善预后。

### 实际V2与hook的碰撞构造

独立固定一个32维随机目标投影R。选择单位向量

\[
v\in\ker\!\begin{bmatrix}A_u\\R\end{bmatrix}.
\]

192+32<256保证存在非零零空间。先生成16组8槽，去掉基础S在v上的分量，再对其中两个槽分别加v、减v。由此均值、U、L及投影目标不变，但置换不变的原槽内容

\[
q(S)=K^{-1}\sum_k(v^\top S_k)^2
\]

增加2/K=0.25。它不依赖固定槽索引；置换整个集合不改变q。内容loss、HSIC与方差项均不能分辨此对构造。默认两种子L差异最大1.55e−15，目标差异最大5.11e−15，内容loss差均0。

这一目标控制调用实际`content_set_loss`，但投影目标是声明的生成目标，**不是实际ContentReference的原始token聚类管线**。也没有证明这两组槽能由同一真实编码器与可实现的患者输入同时产生。目标投影和模型零空间只用于证明代理不构成一般充分性保证。

额外用真实`SlotPluginHost`及真实替换hook接一个明确声明的生成矩预测器：原生q差0.25，替换后预测差1.11e−16。此backbone不是受保护的原版生存头，没有加载患者checkpoint。它证明接口允许一个可用于预测的置换不变信号被消除，不证明原版临床预测发生了此种消除。

## 3. 低summary-HSIC不保证私有全集不含共有信息

精确枚举16个假想患者状态(b,m1,m2,a)，其中b∈{−1,1}、m1∈{−1,2}、m2∈{−2,1}、a∈{0.5,1.5}，四者独立均匀。C的64维均为b；每个U有192坐标，交替重复以下两个槽向量，组成8槽：

\[
u_+=(m_1+a,m_2+ba,\ldots),\quad
u_-=(m_1-a,m_2-ba,\ldots).
\]

坐标均值和均方只含m1、m2、a²，与b独立；但同患者槽内两个坐标的交叉协方差等于ba²，其符号精确恢复b。这一统计也对槽置换不变。因此在声明的有限总体中

\[
I(C;\mathrm{summary}(U))=0,\quad I(C;U_{1:8})=\log2.
\]

实际源码summary_hsic输出−8.23e−19，处于浮点误差范围；所有列方差与Gram退化检查通过。这里16是精确枚举的总体状态，不是16位独立抽样的真实患者，也没有进行显著性检验。源码本来已说明其范围是summary；这不是发现一个实现bug，而是明确不能升级的语义结论。

不能简单补上交叉二阶矩就称问题解决：更高阶或非线性重编码还可避开有限矩，192维全协方差也会显著增加小患者批的估计负担。HSIC不是数值MI上界；V1的Gaussian KL及当前原型的rate也有不同随机变量、归一化和参考分布，不能用此结果相互替代。

## 4. 三个候选与自主选择

| 候选 | 问题 → 方法作用 → 可检验预测 → 对照 → 成功／失败解释 |
|---|---|
| 普通原槽残差Z=S+αF(S) | 当前重编码可能丢方向 → 增加原槽直达 → 旧F零空间的差异能保留 → 原V2、S直通、同参数原头 → 只证明旧碰撞消除；若存在F的特征值−1/α仍会抵消。不能当全局无损方案。 |
| **优先：有范数界的原槽残差** | 普通残差可新生抵消 → 约束全接口残差Lipschitz常数q<1 → 任意两组输入距离至少保留1−q比例、可恢复 → 原V2／普通残差／S直通，读出固定 → 通过仅说明固定参数接口不制造碰撞；若预测无增益、内容头被绕过，语义和任务目标仍失败。 |
| 备选：逐槽可逆分块 | 汇总C丢失槽对比 → 每槽QS_k=[C_k,U_k]完整保留 → 解析恢复、参数匹配下仍可访问原内容 → 正交恒等重编码、同宽普通MLP、禁止先汇总C的控制 → 只有无损重参数化；可逆不识别语义。重新先池化C会重现损失。 |

### 为什么普通残差还不够

构造真实小尺寸V2权重，使F=−P，P投影到前6个坐标。α=1时Z=(I−P)S，原输入差2.82843被完全抵消；α=0.5时保留差1.41421。实际模块验收通过。这是允许的参数反例，并非默认初始化实际发生该抵消。

### 优先候选的充分条件与解析验收

在F仍为当前仿射形式、采用槽张量Frobenius范数时，均值／对比子空间正交，所以全局算子范数恰为

\[
L_F=\max\{\|N\|_2,\|M+N\|_2\}.
\]

选参数依赖但不依赖当前患者输入的标量a，使q=|a|L_F<1，定义Z=S+aF(S)。则三角不等式给出

\[
(1-q)\|S-T\|\le\|Z(S)-Z(T)\|\le(1+q)\|S-T\|.
\]

因此该固定参数映射单射。本轮取a=0.5/max(1,L_F)，测试q≤0.5；不是后续预测超参数选择。解析逆为

\[
\bar S=(I+a(M+N))^{-1}(\bar Z-ab),\quad
S_k-\bar S=(I+aN)^{-1}(Z_k-\bar Z).
\]

两个默认种子最小奇异值分别0.70532／0.71741，大于保证下界0.5，最大恢复误差均3.11e−15；小尺寸控制误差1.33e−15。它们是数值验收，充分条件与证明本身不依赖这些种子。通用非线性分支需重新证明整个分支的范数界；不得把此公式直接套到后来加入的关系模块、归一化或注意力上。

精确算两个256×256奇异值分解需要O(D³)开销，本轮未测训练吞吐；额外前向常规开销为缩放与残差相加，无新增可训练矩阵。当前V2单模态175072参数，两模态350144参数，残差形式沿用这些参数。可采用矩阵Frobenius范数或各因子Frobenius范数乘积作为可证明的上界，代价更低但可能过于保守，使分支几乎不起作用。有限次幂迭代通常只是谱范数近似，不能宣称严格上界证书。

若后续实现，会明确选择哪一种上界、数值安全裕量及是否对归一化系数求导，并单独验收。detach系数仍可能保持前向界，但改变优化梯度，不能混成同一实现。当前仅有诊断中解析残差，没有训练网络接口或默认开关。

### 原槽保留的代价：旁路与反塌缩边界

固定参数接口不丢S，不代表上游编码器训练时不丢患者信息，也不保证下游头访问该信息。原槽通路可以让预测绕过C/U辅助分工；此时私有KL只约束辅助分支，不能写成对整个预测通路的MI约束。保留坏信息、读出集中和上游塌缩均仍可能存在。

若残差增益a和分支输出同时初始化0，预测损失对两者梯度均0；只有a=0而分支非零时，分支初始任务梯度为0，但a梯度可非零。本轮标量控制分别测得(0,0)及(4,0)。不能把“双零初始化且可学习”当作自动启动的分支。

备选正交QS保留逐槽Gram、余弦和有效秩，不会凭空增加内容；本轮逆误差1.11e−15、Gram误差3.55e−15。若精确解码QᵀQS再接不变头，主任务对Q的梯度解析抵消，数值−1.11e−15。若将C_k先均值化再广播，小尺寸4×8输入秩重新降至26/32。因此“可逆共享／私有拆分”须完整保留每槽两部分且让任务直接使用分块，否则不能承诺分工。

## 5. 后续实现范围与可归因验收，不在本轮执行

槽数先固定：WSI 8个256维原生槽、OMIC 8个256维原生槽。优先候选生成同形Z，不增加／选择槽；C与U暂作明确标注的辅助表示，不能据此声称实现了跨模态共有和独有。**本轮没有选择新的MI估计器，也没有解决有用共享、私有任务信息与有害噪声的可识别性。** 互信息部分仍须定义以患者为样本、以观测内容和任务增量为目标的随机变量，避开已证伪的收费解释；不能给残差模块改名就称“槽互信息机制已完成”。

若进入实现阶段，只新增独立adapter及API／梯度验收，不改第三方原文件或现有队列。先固定以下非训练控制：置换等变；三组秩和碰撞；严格q界与逆；共享／私有路径梯度；单零／双零初始化；dtype与数值安全；范数计算开销。然后才决定是否锁定一组新的合成训练协议，本轮新增训练次数仍为0。

读出作为独立轴：先完成原版读出下的原版、V2_content、V2_separate、同配置有界残差对照，再研究全槽读出。新路线拟用每模态z_m=mean_k phi_m(Z_mk)，拼接[z_w,z_o]接生存头；必要时另外拼接C是一个额外消融，不默认加入。phi共享于同模态各槽，无位置编号、动态槽权重或Top-K；输出对各模态槽置换不变。它有均值瓶颈，不能保证把接口无损信息全部留到预测。

Deep Sets、直接均值、关系后对称汇总分别对照；关系模块应设同参数／近似FLOPs的逐槽MLP控制。注意力加权若研究，须明确是动态门控，不能冒充均匀全槽利用。原版全cross路径、mask与辅助目标先审计匹配，不能同时改训练目标、槽适配器和读出后单一归因。本轮没有启动此矩阵。

患者阶段仍缺执行适配、匹配训练路径、模型选择与独立测试。旧best验证结果、20次固定checkpoint复评与单次训练峰值不能替换这些缺口。保留原先分层设计：训练／内层选择／外层测试相互隔离；数据不足时承认估计不确定性，不能反复看同一验证集选方案再称独立测试。任何未来患者执行需用户单独授权。

## 6. 原始文献与新颖性边界

Invertible Residual Networks已将范数约束用于可逆残差网络；本轮的残差充分条件属于已有方法族，针对当前V2的均值／对比仿射结构给出可直接计算的审查，不是新的一般可逆性定理。[ICML 2019原论文](https://proceedings.mlr.press/v97/behrmann19a.html)、[作者实现](https://github.com/jhjacobsen/invertible-resnet)。

核对作者[spectral_norm_fc.py](https://github.com/jhjacobsen/invertible-resnet/blob/master/spectral_norm_fc.py)，实现用有限幂迭代更新u/v，以uᵀWv估计sigma，再软缩放权重。源码本身说明其奇异向量是近似值。由此不能推导任意训练步都满足严格全局范数上界；本轮解析控制使用实际SVD，不声称复现该完整模型。

RevNet也有可重建中间激活的架构，但原论文主要解决反向传播的激活存储；它不为本任务提供共有／私有语义识别或患者收益保证。[2017原论文](https://arxiv.org/abs/1707.04585)、[作者实现](https://github.com/renmengye/revnet-public)。本轮只核对其公开论文说明与仓库范围，没有移植或声称完整复现其实现。

同近期共享／私有与信息瓶颈近邻工作的区分继续以已有文献审查为准。本轮补的是已知可逆网络近邻，**未完成新的全面近年文献覆盖**。在生存删失、真实多模态语义、独立测试与跨seed收益未解决前，不能写成顶会方法、SOTA或患者改进结论。
