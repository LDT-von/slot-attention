# 私有预算内收费：24次多因素消融与未通过的改进假设

**决定：不将轻收费或连续rate提升为默认机制，也不继续扫eta。**在保留网络与全槽均值读出的情况下，更强收费确实压低了rate，但未同时建立内容保留和预测优势。当前整条新架构仍不是可送患者训练的定型方案。本轮保留一个有用的正结果：多因素任务中，无私有收费时，三个种子均检出全槽相对每模态最佳单槽的有限内容可读性增量。

本地父提交`32a17a6`。在独立检出执行，第三方、原版/V2、服务器运行队列与历史回执不修改。远端本轮查询未连接成功，不将上一轮远端快照当作当前状态。本轮不合并或推送。

## 1. 问题、机制作用、可检验预测与对照

问题 → 旧平顶预算在批次槽平均rate低于容量时不收费，可能允许容量内的重复；但总rate同时收费于有用信息与先验失配。

机制作用 → 用同一个分段线性预算族`phi_eta(R)=eta R+(1-eta)[R-1]+`，只改变阈值下斜率。eta0保留原损失与梯度，eta.1在阈值以下收费、以上斜率仍为1；eta1连续收费。它没有增加MI估计器、内容监督、关系或注意力模块。

可检验预测 → 若阈值内压力不足是可修复的关键因素，增加压力应减少无效开销，同时保留任务内容，并在配对预测中显示可重复的好处。若rate下降而必要内容可读性降低，则不能把低rate当成功。

对照 → 无私有收费、原平顶、eta.1、eta1，共四臂。所有臂保留随机共有路径、.1共有KL、.1cross预测、原始全槽均值读出；后三臂私有权重.3、容量1 nat不变。新目标在独立文件中实现，不修改`CrossmodalSharedBottleneck`或原目标函数。

## 2. 实际训练与评估协议

两任务×3个新数据/训练复合seed653/677/701×4臂，共24次全新合成训练，每次500步Adam .003、batch32，无裁剪、无调度，固定最后一步checkpoint。共12000次核心优化更新，CPU两线程；训练计时合计191.6秒，不含探针。不是患者epoch或GPU预算。

模型每模态2槽、width16、共有/私有维数4、4时间bin，7364参数；不代表患者默认8+8槽配置。6个任务×seed组内初值、数据/标签及噪声调度一致；跨两个任务也复用同seed初值，实际只有3种初值hash，不能说是6个独立seed。

每个假想患者有共有S、WSI两个私有因素P0/P1、组学两个Q0/Q1，以及独立无关量。每模态16个token，包含两类固定type元数据、S及相应私有因素的.05噪声观测、无关量及额外噪声。只用训练512行拟合连续特征标准化，type列不变；probe-fit/validation/test为192/128/384行。网络不直接接收潜在风险或诊断答案。这个方便的合成观测结构不是临床组织或通路标签。

factorwise四个hazard分别依赖P0/P1/Q0/Q1；paired_xor依赖四种跨模态配对异或。独立删失bin概率(.1,.1,.1,.7)。每模型5次配对随机前向分别算NLL再平均，是24次训练而非120次。另报完整均值诊断前向：G用后验均值，私有均值也在这个G下计算；不是将给定随机G的私有均值与G均值混搭。

附加的“观测bin一致性分数”以负存活曲线和作为风险，按本任务的“删失时已生存通过该bin”约定处理可比对；同bin两个事件不比较，预测分数相同计半分。它不是原患者队列C-index，不能与历史临床数值比较，也不用于选模型。

## 3. 探针校准、目标澄清及后置诊断

训练前，保持旧核族/验证选择规则，已知按角色放置的四因素码全槽相对单槽归一化增量.50296；精确复制码0；错配目标.00072。通过预定>.25、<1e−10、<.05门槛后才训练。

XOR的四种预测关系在同时翻转四个私有比特后不变。因此，恢复四个原始比特是覆盖诊断，不能当作任务充分性的唯一标准。补充澄清文件在启动执行后、首次查看神经臂分数前写入；不声称早于训练完成或原始预注册。训练源码、目标、种子、原始探针未改。后续使用相同冻结表示/fit/validation/test，额外预测四个真正进入hazard的效应；正控增量.77223、复制0、错配.00978通过。factorwise效应等于原因素，复用原诊断，未重复拟合。

在查看汇总效应探针后，又对原始展平私有槽做了效应可读性定位，明确标为**后置分析**；没有新增神经训练、改变核族或重选架构。所有阴性只表示有限探针未检出，正控未匹配学习表示的全部噪声与复杂度。

## 5. 原始槽、随机性与训练稳定性

XOR中，原始私有采样展平后的任务效应增量，各臂约−.00054/0/0/0；phi汇总后的效应增量也接近0。均值原始槽有较弱的.00212/.02439/.01601/.00640，而非稳定的有效协同。因此本次不支持“只换池化就能修复XOR”的解释，也不能证明编码完全没有信息。

只看原始比特则容易误判：连续收费XOR的均值因素增量仍约.253，实际采样仅.00020；共有均值可能保留微小编码，采样会改变可读性。均值结果不能为实际随机预测通路的信息保留背书。

平顶臂的批次中“至少一个槽平均rate超过1”的比例，在分时任务为.2853，在XOR为.0280；这支持其多数批次处于平顶区的具体观察。轻/连续收费能在区内继续作用，但未因此学会XOR。无收费臂的该比例只是未应用的阈值监视，不能叫实际预算激活。

所有12000次核心更新均为有限值，最大梯度L2为2.65905。四个时点另有NLL、cross、共有rate和已加权私有费的梯度范数及方向余弦；500步曲线保存在忽略的合成缓存。没有启动裁剪或其他反塌缩干预。

更强收费下随机私有槽有效秩可接近1.84（两槽上限2），而均值槽秩约1.2—1.4，内容却减少。这再次表明采样几何可以撑开，不能单独证明成功。此观察是小型合成网络，不迁移为V2或R5干预结论。

## 6. 如何收敛这条路线

问题 → 希望减少无效重复而保留有用私有内容与协同。方法作用 → 预算内收费避免平顶区不收费。可检验预测 → 降rate、保内容且预测不依赖单一偶然seed。对照 → 同网络四臂与校准探针。结果解释 → 收费压低rate，但多数收益未稳定、部分内容及预测恶化，XOR仍未检出；**不升级、不扩eta扫描**。

下一研究重点应回到原生预测信息保留及观测内容可识别性。先审查源代码和数学假设，明确能保留什么、额外旁路又会允许什么退化解；不据本轮最低NLL改默认参数，不追加关系/注意力模块，不立刻扩大患者或合成队列。当前没有足够证据支持把此预算改动作为新架构的主要方法贡献。

本族只是标准rate/分段正则的消融，没有产生新MI估计器或可直接宣称的新颖性。理论依据与近邻关系见前一轮`finite_content_review_20261102.md`，数学恒等式不变。主网络的操作性共有/私有分支依旧未被证明具有生物学语义。
