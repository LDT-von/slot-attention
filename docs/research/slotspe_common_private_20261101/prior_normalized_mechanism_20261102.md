# 先验归一化私有槽：解析信息预算与读出坐标

## 修正对象

旧网络将原始随机槽U送入私有读出，但用依赖G的条件先验r(U|G)约束它。公共偏移mu_r(G)和尺度sigma_r(G)可被免费带入U。直接vCLUB修正了目标对象，但五seed确认尚无预测优势、槽级分工仍未建立。

本候选保持全部参数、槽数和Deep Sets。唯一前向变化是私有读出接收

V=(U-mu_r(G))/sigma_r(G)

而不是U；公共G继续独立进入最终预测。没有新增估计器、注意力或Top-K。默认病理8槽、组学8槽不变，合成小配置各4槽。代码在独立子类中实现，旧网络与历史回执均保留。

## 严格恒等式与信息对象

令A包含全部编码输入和公共表示。对固定参数、每个A，q(U|A)为对角高斯，r(U|G)为正方差高斯，变换T_G是仿射双射。于是

KL(q(U|A)||r(U|G)) = KL(q(V|A)||N(0,I)).

归一化后的后验参数为mu_V=(mu_q-mu_r)/sigma_r，logvar_V=logvar_q-logvar_r。使用原有有效方差截断值，不能对归一化参数再独立截断，否则破坏恒等式。

对患者总体取期望，完整联合rate R满足

R = I(A;V)+KL(q(V)||N(0,I)) >= I(G;V).

这里是总体期望的数学关系；有限生成批量上的平均KL只是R的估计，不自动构成总体互信息的置信上界。

若将V按槽分组，还可写成

R = I(A;V)+TC(V)+sum_k KL(q(V_k)||N(0,I_k)).

因此旧解析KL现在对应**实际送入私有读出的V**的固定参考信息预算，而不是只约束原始U相对G的增量。这里R为全部模态、全部槽、全部维度的联合KL；每维平均值必须乘以联合维数才能用于上述数值界。默认联合维数512，当前合成小配置32。

例：U=aG+bP+epsilon、r均值=aG且方差固定，则V不含免费位置复制aG。若模型把G再次编码到V里，它会进入固定参考KL预算；不存在“条件先验位置本身直接出现在私有读出而不付费”的同一构造。

这不代表KL下降就证明I(G;V)下降，也不代表达到统计独立。R同时收费于有益增量、噪声分布失配和跨槽依赖。R趋零会使整个私有表示失用，仍需任务保留约束。公共/私有生物语义以及最优rate大小均未识别。

## 保留的旁路与退化解

- 公共G可能承担全部预测；应继续检查相对G的真实可读增量。
- 后验可重新编码G到V，但要支付预算，且有限预算可能优先删除有益私有因素。
- 同患者槽仍可复制相同P；联合rate并不保证每个槽独有或全部被利用。
- 先验参数现在接受预测梯度，活跃参数路径发生变化；beta0归一化对照不可省略。
- 给定G，(G,U)与(G,V)可互相恢复。无限容量解码器下，这只是重参数化；不能把可逆坐标变化本身当作全球首次提出的新架构或性能保证。当前有限MLP和梯度路径可能改变训练行为，须实验归因。

## 本地验收与2×2对照

四项测试通过：KL在双精度随机高斯上相等；改变a不改变归一化私有代码；同权重/同噪声的两宿主rate相同且参数数相同、梯度有限；先验为N0时读出精确退化为原版。测试仅为生成张量，不是患者结论。

锁定36次小型生成训练：3任务（独立、相关、协同）×3新seed（109/131/157）×2坐标（raw/normalized）×2beta（0/.3），每次300步。同组初始化、样本调度、后验基础噪声一致，固定末步；另192/128/384个样本作probe-fit/validation/test。每checkpoint5次随机NLL，不是5次训练。

beta0对照用于识别坐标/梯度路径自身的作用；同坐标beta0与.3识别rate约束作用。不得只报告normalized .3相对raw 0的差值。结果见prior_normalized_ablation_receipt.json；本节先写机制和预定比较，不预设结果。
