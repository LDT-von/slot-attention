# SlotSPE 研究总览

更新：2026-10-22。本页集中回答“研究什么、已经知道什么、还缺什么、下一步做什么”。任务执行状态统一记录在 [PROGRESS.json](PROGRESS.json)，全部历史材料见[分类目录](research/README.md)。

## 先看这几句话

当前有患者测量支持的核心槽现象是**重复表示、重复读取，而且选中后仍重复**。还没有证明这些槽一定发生混槽、碎片化或内容遗漏。

冗余之外，目前值得优先追查的是**重构监督是否真正要求槽保存当前样本的信息**。原版WSI重构头已有构造反例：共用固定槽字典也能重构不同目标，但尚未证明训练后的模型采用了这个解。

另外查清两类结构问题：选槽器的直接融合主梯度断开；“未选中”并不等于内容完全退出预测。它们应作为归因对照，不直接当作新的患者损害或方法收益。

几何是条件性支线：独立patch特征集合相同、缺少空间绑定时，原版无法区分分区与棋盘排列。上游空间信息与真实组织任务仍需另查。

**当前尚未建立：上述机制导致患者预测损害，或某个修正稳定提高患者性能。** 文献动机、源码事实、生成数据反例和患者证据分别登记。

## 怎样读证据

| 判断 | 含义 |
|---|---|
| 已观察 | 在指定输入、权重和协议中测到现象；适用范围随记录保留。 |
| 结构事实 | 原版实现确实如此；不能自动升级为内容错误或预测损害。 |
| 条件反例 / 接口边界 | 在明确条件下，某种强保证不成立；不代表自然训练经常发生。 |
| 待验证 | 目前缺直接判据或必要材料。 |
| 强说法已否定 / 不受支持 | 现有证据足以排除过强表述，或没有支持它；不抹掉较窄事实。 |
| 不适用 | 原版没有所假设的结构，不能凑成一个问题。 |

证据来源同时标明：源码、生成输入、历史本地患者汇总已复算、本机GPU公开汇总、服务器报告未验原件、文献动机。不同来源不能合并成额外独立患者样本。

## 哪些旧说法不能继续使用

| 旧说法 | 当前有效表述 / 覆盖依据 |
|---|---|
| 模型必然看不见组织比例 | 已被完整模型比例对照否定。单次归一化可能有分配总量歧义，不能推出完整模型普遍丢失比例。 |
| 给coords换值、输出不变，证明患者空间失败 | 旧例只是未消费字段检查。现在以分区/棋盘邻接真值说明较窄的接口边界。 |
| 近同槽差异收缩，证明内容恢复失败 | 无内容真值，不成立。最新03回执排除了精确同态RMS舍入量的无意义比值。 |
| 全部槽的cos都高，所以已证明混槽/遗漏 | 仅支持重复表示/读取。混槽、碎片化和遗漏分别需要内容依据。 |
| 20个独立fold/seed任务 | 当前公开记录为20条完成记录、15个唯一配置；5个seed3配置重复。 |
| 关闭门控后C-index一样，说明预测完全相同 | 风险仍变化；本机GPU两侧关闭MAE约0.001075，最大绝对差约0.014302。 |
| 77人与历史71人是同一结果 | 两处GPU边界文字沿用了旧71人模板；本机GPU77人、历史71人、服务器77人分别保留。 |
| 主辅梯度多数同向，所以目标没有问题 | 梯度关系不等于语义/内容约束充分，P7.3仍需独立验证。 |
| 强制确定性top-2重算，就能测出门控数值问题吃掉多少性能 | 它同时改变选槽mask，所得差值不是归一化问题的独立效应；固定mask只修软权重对冻结原版融合logits无直接影响，训练影响另查。 |

## 文献改进到底对应哪一层

此前整理了8篇本地论文与16篇扩展研读条目。最新[严重问题与槽相似性再评估](research/slotspe_extended_literature_20261022/严重问题与槽相似性_证据再评估_20261022.txt)补充核查包括SlotSPE在内的14篇一手论文相关正文、关键实验与局限，并非穷尽全部文献。

当前研究重心是**槽的内容承载与监督充分性**。高cos是诊断线索；原始SA允许无害的共同背景，DIAS表明仅去冗余的识别收益有限，DINOSAUR显示重构误差更低仍可能伴随实例分离变差，Slot-BERT也提醒过强不相似约束会伤害对象学习。PathoSlot直接讨论临床端点语义，但不证明SlotSPE已失效。应以内容混合/遗漏、事件语义和必要空间关系定义功能缺口，不能用降低cos代替验收，也不能由尚未证明患者损害排除研究意义。当前仍未确认SlotSPE患者内容故障或修正收益。

| 作用层与问题 | 已登记方法 | 对SlotSPE的迁移判断 |
|---|---|---|
| 分配混合、平局、重复读取 | MESH；普通Sinkhorn作为对照 | 可以对到原生SA内部；要分别测分配、value更新、槽内容与预测。 |
| 固定容量、冗余候选 | DIAS、MetaSlot、Adaptive Slot Attention | 需先证明容量/内容覆盖缺口；DIAS选后再聚合与只删槽分开。MetaSlot候选上限、位置/组合限制仍存在。 |
| 冷启动、迭代优化 | CoSA、Query Optimization、Clustering-based Initialization、隐式微分与迭代平滑 | 输入可分性、优化收敛、患者特异性是不同条件，不能只看最终槽cos。 |
| 槽内内容、监督目标质量 | CODA、OCEBO、属性解耦、概念条件槽分解 | 优先启发P7.3的内容检验；不直接证明预后生物概念已绑定。 |
| 可辨识性 | Probabilistic Slot Attention | 先核对理论假设；不是把槽编号固定就得到保证。 |
| 几何、多层输入、关系 | Invariant Slot Attention、MUFASA、关系抽象方法 | 需要匹配坐标/层特征/关系任务；有的方法作用在槽后，并非SA插件。 |

详细定位与迁移边界：[8篇逐篇核查](research/slotspe_paper_problem_map_20261021/逐篇论文问题与八项覆盖核查.txt)、[16篇扩展研读](research/slotspe_extended_literature_20261022/扩展文献研读与SlotSPE迁移判断.txt)。
